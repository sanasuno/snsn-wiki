## コレクションローダー
ウィキページ用のコレクションローダーを `./src/content.config.ts` として作成します。  
`./src/content/wiki` 配下にある `.md` または `.mdx` ファイルを収集して `wiki` コレクションとして利用できるように定義します。

```ts
import { defineCollection } from 'astro:content';
import { glob } from 'astro/loaders';
import { z } from 'astro/zod';

const wiki = defineCollection({
    loader: glob({ base: './src/content/wiki', pattern: '**/*.{md,mdx}'}),
    schema: z.object({
        title: z.string(),
        description: z.string().optional(),
        order: z.number().default(0),
        aliases: z.array(z.string()).default([]),
        tags: z.array(z.string()).default([]),
        date: z.coerce.date().optional(),
        updated: z.coerce.date().optional(),
        draft: z.boolean().default(false),
        showSubpanel: z.boolean().default(true),
        isSubPage: z.boolean().default(false),
    }),
});

export const collections = { wiki };
```

`schema` の各項目の説明です。
- `title`: ページのタイトル（必須）
- `description`: ページの説明（任意）
- `order`: ページの表示順（数値が小さい方が上に表示される）（任意、デフォルト0）
- `aliases`: ページの別名（任意）
- `tags`: ページのタグ（任意）
- `date`: ページの作成日（YYYY-MM-DD形式）（任意）
- `updated`: ページの更新日（YYYY-MM-DD形式）（任意）
- `draft`: ドラフトフラグ（true/false）（任意、デフォルトfalse）
- `showSubpanel`: サブパネル表示フラグ（true/false）（任意、デフォルトtrue）
- `isSubpage`: サブページフラグ（true/false）（任意、デフォルトfalse）

## ユーティリティ関数
`@lib/path.ts` にパス関連のユーティリティ関数を記述します。

### removeTrailingSlash()
末尾のスラッシュを削除する関数です。

```ts
export function removeTrailingSlash(path: string): string {
    return path.replace(/\/$/, '');
}
```

### getLocale()
ページIDからロケールを取得する関数です。ページIDを `/` で分割したときの先頭の要素をロケールとして扱います。有効なロケールかどうかを `isLocale()` 関数で判定し、有効ロケールだった場合はそのロケールを返し、有効ロケールでない場合にはエラーをスローします。

```ts
import type { Locale } from '@i18n/i18n.config';
import { isLocale } from "@lib/locale";

export function getLocale(pageId: string): Locale {
    const parts = pageId.split('/');
    if (isLocale(parts[0])) {
        return parts[0] as Locale;
    }
    throw new Error(`[Invalid id format] ${pageId}`);
}
```

### getRawSlug()
ページIDから生のスラッグを取得する関数です。ページIDを `/` で分割したときの、先頭を除いた要素を `/` で再結合して返します。

```ts
export function getRawSlug(pageId: string): string {
    const parts = pageId.split('/');
    return parts.slice(1).join('/');
}
```

### dividePageId()
ページIDを分割して、ロケールと生のベーススラッグを抽出する関数です。与えられたページIDに `getLocale()` 関数と `getRawSlug()` 関数でそれぞれロケールと生スラッグを取得し、まとめて返します。

```ts
export function dividePageId(pageId: string): {locale: Locale, rawSlug: string} {
    const locale = getLocale(pageId);
    const rawSlug = getRawSlug(pageId);
    return {locale, rawSlug};
}
```

### normalizeSlugLike()
スラッグを正規化する関数です。まず、与えられたスラッグを `NFKC` で正規化して小文字化し、先頭と末尾の空白を除去します。さらにその結果が `index` だった場合は空文字を返し、それ以外の場合では末尾の `/index` を削除します。

```ts
export function normalizeSlugLike(rawSlug: string): string {
    const normalized = rawSlug.normalize('NFKC').toLowerCase().trim();
    return normalized === 'index'
        ? ''
        : normalized.replace(/\/index$/, '');
}
```

### getNormalizedSlug()
ページIDから正規化されたスラッグを取得する関数です。与えられたページIDに `getRawSlug()` 関数を用いて生スラッグを取得し、さらに `normalizedSlugLike()` 関数で正規化します。

```ts
export function getNormalizedSlug(pageId: string): string {
    const rawSlug = getRawSlug(pageId);
    return normalizeSlugLike(rawSlug);
}
```

### getBaseUrl()
サイトのベースURLを取得する関数です。環境変数から `BASE_URL` を返します。

```ts
export function getBaseUrl(): string {
    return removeTrailingSlash(import.meta.env.BASE_URL);
}
```

### getLocaleBaseUrl()
与えられたロケールのロケールベースURLを取得する関数です。ベースURLの後ろに `/${locale}` をつけたURLを返します。

```ts
export function getLocaleBaseUrl(locale: Locale): string {
    return `${getBaseUrl()}/${locale}`;
}
```

### getWikiBaseUrl()
与えられたロケールのWikiページのベースURLを取得する関数です。ロケールベースURLの後ろにさらに `/wiki` をつけたURLを返します。

```ts
export function getWikiBaseUrl(locale: Locale): string {
    return `${getLocaleBaseUrl(locale)}/wiki`;
}
```

### getWikiUrl()
与えられたWikiページのページIDから、そのページのURLを取得する関数です。スラッグの正規化処理を適用します。

```ts
export function getWikiUrl(pageId: string): string {
    const locale = getLocale(pageId);
    const slug = getNormalizedSlug(pageId);
    return removeTrailingSlash(`${getWikiBaseUrl(locale)}/${slug}`);
}
```

### getCurrentPath()
与えられた `Astro.url` から現在のパスを取得する関数です。与えられたURLの `pathname` を末尾の `/` を削除して返し、空になった場合は  `/` を返します。

```ts
export function getCurrentPath(url: URL): string {
    return removeTrailingSlash(url.pathname) || '/';
}
```

### isPathActive()
対象のスラッグが現在のパスを含むもしくは一致するかどうかを判定する関数です。主にナビゲーションにおいて現在の位置を示すために使用されます。  
この関数は対象のスラッグと現在のパスを引数として受け取ります。ただし、現在のパス `currentPath` は `Astro.url.pathname` を渡すことを想定していますが、これはサイトのベースURLやロケールを含むため、それらを取り除く必要があります。  
そのため、まずは `getBaseUrl()` 関数でベースURLを取得し、 `currentPath` がベースURLで始まっている場合はこれを取り除き `relativePath` として代入します。なお、ベースURLで始まっていない場合は `relativePath` に `currentPath` をそのまま使用します。  
次に、取り除いたパスを `/` で分割します。ただし `relativePath` は `/` で始まるので、分割した配列の2番目がロケールかどうかを `isLocale()` 関数で判定します。  
ロケールが見つかった場合は残りの部分の先頭に `/` を挿入したものをスラッグとして、見つからなかった場合は `relativePath` 全体をスラッグとして扱います。  
最後に、判定対象のスラッグが `/` だった場合はスラッグと一致するかどうか、それ以外の場合にはスラッグと一致するもしくはスラッグの末尾に `/` を挿入したもので始まるかどうかを判定して返します。

```ts
export function isPathActive(targetSlug: string, currentPath: string): boolean {
    const base = getBaseUrl();
    const relativePath = currentPath.startsWith(base) ? currentPath.slice(base.length) : currentPath;
    const [ _, maybeLocale, ...rest] = relativePath.split('/');
    const currentSlug = isLocale(maybeLocale)
        ? `/${normalizeSlugLike(rest.join('/'))}`
        : relativePath;
    return targetSlug === '/'
        ? currentSlug === '/'
        : currentSlug === targetSlug || currentSlug.startsWith(`${targetSlug}/`);
}
```

## 動的ルーティング
`./src/pages/[locale]/wiki/[...slug].astro` を作成し、動的ルート用のページとします。   
- スラッグ部分は `[...slug]` のレストパラメータ形式を採用することで、任意の深さのスラッグにマッチします。  
`getStaticPaths()` 関数で `locale` と `slug` を出力することで、対応するページのパスを生成します。実際の処理は `@lib/pages` の `resolveWikiPages()` 関数で行います。

### resolveWikiPages()
ウィキページを解決する関数です。ウィキページ収集、スラッグ生成、衝突の検知、ロケールのフォールバック判定など、様々なロジックを処理します。

#### ウィキページ収集
`getCollection()` 関数を用いてウィキページを収集します。ただし、下書きページ（ `page.data.draft === true` のページ）は除外します。

```ts
const wikiPages = await getCollection('wiki', (page) => !page.data.draft);
```

#### ページデータ格納
収集したページを `pagesBySlugLocale` に格納していきます。これは各ページのスラッグとロケールをキーとする配列です。  
また、スラッグを生成するときに正規化を行いますが、この過程で衝突するファイルを検知するため、並行して正規化前後のページIDを `normalizedIdOwners` に格納します。

```ts
const pagesBySlugLocale: Record<string, Partial<Record<Locale, CollectionEntry<'wiki'>>>> = {};
const normalizedIdOwners: Record<string, Set<string>> = {};
```

各ページのページIDに `getLocale()` 関数と `getNormalizedSlug()` 関数をそれぞれ適用し、`locale` と `normalizedSlug` を取得します。各ページの `normalizedSlug` と `locale` をキーとして、ページ内容を `pagesBySlugLocale` に登録します。  

```ts
for (const page of wikiPages) {
    const locale = getLocale(page.id);
    const normalizedSlug = getNormalizedSlug(page.id);
    if (!pagesBySlugLocale[normalizedSlug]) {
        pagesBySlugLocale[normalizedSlug] = {};
    }
    pagesBySlugLocale[normalizedSlug][locale] = page;
}
```

#### 衝突検証
もし複数の異なるファイルが同じ `normalizedSlug` に正規化される場合、後から処理された方が先に処理された方を上書きしてしまいます。この衝突を避けるため、検出する必要があります。  
そこで、正規化後のページID（ `normalizedId` ）をキー、正規化前のページID（ `page.id` ）を値として `normalizedIdOwners` に格納します。  
衝突が起こった場合は、同じ `normalizedId` に対して複数の `page.id` が登録されます。これをチェックすることで衝突を検知できます。  
なお、衝突判定は同一ロケール内だけで行う必要があるため、ロケール情報を持たないスラッグではなく、ロケール情報を含むページIDを用いて比較しています。

```ts
const normalizedIdOwners: Record<string, Set<string>> = {};
for (const page of wikiPages) {
    const normalizedId = normalizeSlugLike(page.id);    
    if (!normalizedIdOwners[normalizedId]) {
        normalizedIdOwners[normalizedId] = new Set();
    }
    normalizedIdOwners[normalizedId].add(page.id);
}
for (const [normalizedId, owners] of Object.entries(normalizedIdOwners)) {
    if (owners.size > 1) {
        throw new Error(`[wiki routing] Multiple owners for normalized ID "${normalizedId}": ${Array.from(owners).join(', ')}`);
    }
}
```

#### フォールバック判定
`pagesBySlugLocale` に格納した `locale` と `slug` の組み合わせで、各ページの URL を生成します。  
あるロケールで元となるファイルがなくとも、別のロケールに同じスラッグのファイルがある場合、それをフォールバックとして代替使用します。このとき、ページには「これが別のロケールによるフォールバックである」という情報を渡します。  
フォールバック解決の優先順位は、本来のロケール、デフォルトロケール、その他の翻訳があるロケール（ `locales` で定義された順番に検証）の順です。いずれのロケールでも翻訳が見つからない場合はエラーをスローします。  
最後に返すのは、 `locale` 、 `slug` 、 `page` 、 `isFallback` の4種類のデータの配列です。

```ts
const resolved: ResolvedWikiPage[] = [];
for (const slug of Object.keys(pagesBySlugLocale)) {
    const availablePages = pagesBySlugLocale[slug];
    for (const locale of locales) {
        const isFallback = !availablePages[locale];
        const page = availablePages[locale]
            ?? availablePages[defaultLocale]
            ?? locales.map((loc) => availablePages[loc]).find(
                (p): p is CollectionEntry<'wiki'> => p !== undefined
            );
        if (!page) {
            throw new Error(`[wiki routing] No page found for slug "${slug}"`);
        }
        resolved.push({ locale, slug, page, isFallback});
    }
}
return resolved;
```

### getStaticPaths()
`./src/pages/[locale]/wiki/[...slug].astro` 内に `getStaticPaths()` 関数を記述し、`resolveWikiPages()` 関数を用いて URL を組み立て、各種 `props` を出力します。

```ts
export async function getStaticPaths() {
    const resolvedPages = await resolveWikiPages();
    return resolvedPages.map(({ locale, slug, page, isFallback }) => ({
        params: {
            locale,
            slug: slug === '' ? undefined : slug,
        },
        props: { page, locale, slug, isFallback },
    }));
}
const { page, locale, slug, isFallback } = Astro.props;
```
