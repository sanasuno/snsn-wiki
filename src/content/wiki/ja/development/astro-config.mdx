`astro.config.ts` はサイト設定を管理するファイルです。非常に重要なファイルのため、ユーザーの編集対象は別ファイルに分離します。
- [[site.config.ts]] : サイトの基本設定を管理するファイル
- [[i18n.config.ts]] : 国際化設定を管理するファイル

## インポート
使用する機能をインポートします。
- `astro.config.ts` およびここでインポートされるファイルではエイリアスを使用できません。相対パスを使用する必要があります。

```ts
import { defineConfig } from 'astro/config';

import { siteConfig } from './src/site.config';
import { translations, defaultLocale } from './src/i18n/i18n.config';

import { remarkWikiLinks } from './src/lib/wikilink';
import { buildCache } from './src/lib/slug';

import mdx from '@astrojs/mdx';
import { satteri } from '@astrojs/markdown-satteri';
import sitemap from '@astrojs/sitemap';
```

## site
サイトのオリジンを決定する変数です。

1. 正規化前の生の URL を `rawUrl` として取得します。環境変数 `SITE_URL` が設定されていればそちらを、設定されていなければ `siteConfig.url` を使用します。
2. URL として正しい形式かどうかを `new URL()` で検証します。
3. URL を文字列形式に戻し、末尾の `/` をすべて削除します。
4. エラーが発生した場合はビルドを停止し、エラーをスローします。

```ts
const rawUrl = process.env.SITE_URL ?? siteConfig.url;
let site: string;
try {
    site = new URL(rawUrl).toString().replace(/\/+$/, '');
} catch (error) {
    throw new Error(
        '[site.config] url is invalid',
        { cause: error }
    );
}
```

ビルド時にサイトの URL のホスト名が `example.com` のままなら警告します。
- ビルド自体は停止しません。

```ts
if (new URL(site).hostname === 'example.com' && process.argv.includes('build')) {
    console.warn('[site.config] url is still "example.com". canonical / OGP / sitemap will be wrong.');
}
```

## base
サイトのベースパスを決定する変数です。サイトがドメイン直下ではなく、特定のディレクトリ以下に配置される場合のパスです。

1. 正規化前の生の URL を `rawUrl` として取得します。環境変数 `BASE_PATH` が設定されていればそちらを、設定されていなければ `siteConfig.basePath` を使用します。
2. `/` で始まるかチェックします。`/` で始まっていない場合はエラーをスローします。
3. `rawBase` の末尾の `/` をすべて削除してから `base` に代入します。削除した結果、空文字列になった場合は `/` を代入します。

```ts
const rawBase = process.env.BASE_PATH ?? siteConfig.basePath
if (!rawBase.startsWith('/')) {
    throw new Error(
        '[site.config] basePath must start with "/"'
    );
}
const base = rawBase.replace(/\/+$/, '') || '/';
```

## locales
利用可能なロケールの一覧です。[[i18n.config.ts]] で設定した `translations` オブジェクトのキーを取り出します。

```ts
const locales = Object.keys(translations);
```

## relativePath
ベースパスを基準にした相対パスとしてのページのパスです。
- サイトマップの対象ページ判定に使用します。

1. `new URL().pathname` で URL からパスネームを取得します。
2. ベースパスに応じた `prefix` を作成します。
3. 対象ページが設定されたベースパスの範囲内にあるか確認します。範囲外の場合はエラーをスローします。
4. ベースパス部分を削除し、先頭と末尾の `/` を取り除いたものを相対パスとして取得します。

```ts
const relativePath = (page: string) => {
    const pathname = new URL(page).pathname;
    const prefix = base === '/' ? '/' : `${base}/`;
    if (!pathname.startsWith(prefix) && pathname !== base) {
        throw new Error(`Page is outside base path: ${page}`);
    }
    return pathname
        .slice(base === '/' ? 1 : base.length + 1)
        .replace(/^\/|\/$/g, '');
};
```

## defineConfig
Astro に渡す設定を定義します。

### site
サイトの絶対 URL を指定します。

```ts
site,
```

### base
サイトの公開ディレクトリを指定します。

```ts
base,
```

### trailingSlash
URL の末尾に常に `/` を付ける設定です。

```ts
trailingSlash: 'always',
```

### markdown
Markdown の解析・変換方法の設定です。

#### processor
Markdown を処理するためのプロセッサを `satteri` で指定し、独自の処理プラグインとして <code>[[wikilink.ts#remarkwikilinks|remarkWikiLinks]]</code> を設定します。

```ts
processor: satteri({
    mdastPlugins: [
        remarkWikiLinks({ base }),
    ],
}),
```

#### shikiConfig
コードブロックのシンタックスハイライトの設定です。ライトモードに `github-light`、ダークモードに `github-dark` を使用します。

```ts
shikiConfig: {
    themes: { light: 'github-light', dark: 'github-dark' },
},
```

### i18n
- 国際化機能の設定です。

#### locales
対応するロケールの一覧です。

```ts
locales,
```

#### defaultLocale
デフォルトのロケールです。[[i18n.config.ts]] で指定します。

```ts
defaultLocale,
```

#### prefixDefaultLocale
デフォルトロケールでも URL に言語コードを付ける設定です。

```ts
routing: {
    prefixDefaultLocale: true
}
```

### integrations
インテグレーションの設定を行います。

#### mdx
MDX 形式を利用するためのインテグレーションです。Markdown の中に JSX コンポーネントを記述できます。

```ts
mdx(),
```

#### sitemap
サイトマップを利用するためのインテグレーションです。

##### filter
サイトマップに登録するページを選別する関数です。

404 ページ、空のパス、ロケール名だけのパスを除外します。

1. ページの相対パスを取得します。
2. 404ページ、サイトのルート、各ロケールのトップページを除外します。
3. スラッグ一覧のキャッシュを作成します。
4. ページがウィキページの場合、スラッグが存在するか確認します。
5. ウィキページ以外のページはサイトマップに含めます。

```ts
filter: (page) => {
    const path = relativePath(page);
    if (/(^|\/)404$/.test(path) || path === '' || locales.includes(path)) return false;
    let slugs: Set<string> | undefined;
    const getSlugs = () => (slugs ??= buildCache().slugs);
    const m = path.match(/^([^/]+)\/wiki(?:\/(.*))?$/);
    if (m) {
        return getSlugs().has(`${m[1]}/${decodeURIComponent(m[2] ?? '')}`);
    }
    return true;
},
```

##### i18n
サイトマップの多言語情報設定です。デフォルトロケールおよび各言語の対応関係を渡します。

```ts
i18n: {
    defaultLocale,
    locales: Object.fromEntries(locales.map(locale => [locale, locale]))
}
```
