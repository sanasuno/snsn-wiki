`./src/pages/[locale]/wiki/[...slug].astro` は、ウィキページの動的ルーティング用のページです。

`getStaticPaths()` 関数の `params` で `locale` と `slug` を出力することで、対応するパスのページを生成します。

## getStaticPaths()
URL の組み立てに必要な `params` とページレンダリングに必要な `props` を出力します。
- 実際の処理はほぼ `resolveWikiPages()` で行っているので、各項目を当てはめていきます。

```ts
export async function getStaticPaths() {
    const resolvedPages = await resolveWikiPages();
    return resolvedPages.map(({ locale, slug, page, isFallback, fallbackLocale }) => ({
        params: {
            locale,
            slug: slug === '' ? undefined : slug,
        },
        props: { page, locale, slug, isFallback, fallbackLocale },
    }));
}
```

## alternateLinks
別ロケールのページへの代替リンク一覧です。全てのロケールについて、ロケールと URL を設定します。

```ts
const alternateLinks = locales.map(loc => ({
    locale: loc,
    href: ensureTrailingSlash(`${getWikiBaseUrl(loc)}${slug}`)
}));
```

## ページレンダー
`render()` 関数を用いて `page` を出力し、`MainLayout` コンポーネントに各種 props を渡します。

```astro
---
const { Content, headings } = await render(page);
---
<MainLayout
    title={page.data.title}
    description={page.data.description}
    locale={locale}
    alternateLinks={alternateLinks}
    type='wiki'
    isFallback={isFallback}
    fallbackLocale={fallbackLocale}
    tags={page.data.tags}
    date={page.data.date}
    updated={page.data.updated}
    id={page.id}
    isSubpage={page.data.isSubpage}
    showSubpanel={page.data.showSubpanel}
    headings={headings}
>
    <Content />
</MainLayout>
```
