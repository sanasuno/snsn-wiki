## i18nについて
snsn-wikiでは、i18n（国際化）に対応しています。  
ここでは、対応するロケールの設定や、翻訳用の関数を作成していきます。

## 翻訳ファイル
`@i18n/key.ts`および`@i18n/keys.custom.ts`に、使用する翻訳キーをそれぞれ`TranslationKey`型、`CustomKey`型として記述します。`TranslationKey`型は`CustomKey`型を含みます。  
システム側で使用するものは`keys.ts`に、ユーザーが自分で翻訳内容を変えたり追加したりするものは`keys.custom.ts`に記述します。  
また、具体的な翻訳を記述する翻訳ファイルも、`@i18n/ja.ts`と`@i18n/ja.custom.ts`のように分離して記述していきます。  
これは、snsn-wiki本体の更新によって、ユーザーの追加した翻訳に影響が及ばないようにするためです。  
翻訳ファイルは、`[key]: [value]`の形式で定義され、それらを各言語ごとにまとめて出力します。

## i18n.config.ts
`i18n.config.ts`は、i18n関連の設定を記述するファイルです。  
利用可能なロケールや翻訳の一覧、デフォルトロケール設定、翻訳関数などが含まれます。

### 翻訳キー
`@i18n/keys.ts`から、翻訳キーの型である`TranslationKey`型をインポートして、そのままエクスポートします。

```ts
import type { TranslationKey } from "./keys";
export type { TranslationKey };
```

### 翻訳ファイルのインポート
`i18n`ディレクトリ配下にある翻訳ファイルをインポートし、すべてまとめて`translations`オブジェクトに格納します。  
ロケールを追加するときは、ここに追記します。

```ts
import { ja } from "./ja";
import { en } from "./en";
import { eo } from "./eo";
export const translations = {
    ja,
    en,
    eo
} as const;
```

### ロケール型
`translations`オブジェクトのキーを`Locale`型として定義します。

```ts
export type Locale = keyof typeof translations;
```

### デフォルトロケール
サイトのデフォルトロケール`defaultLocale`を決定します。デフォルトロケールは、主に各種翻訳やページ遷移のフォールバックとして使われます。  
デフォルトロケールは、`Locale`型の要素である必要があります。

```ts
export const defaultLocale = 'ja' satisfies Locale;
```

### 利用可能なロケール
`locales`は、利用可能なロケールの配列を定義します。

```ts
export const locales = Object.keys(translations) as Locale[];
```

### t()
`t`関数は、与えられた翻訳キーとロケールから、翻訳された文字列を取得する関数です。  
`locale`パラメータを省略した場合、`defaultLocale`が使用されます。  
指定されたロケールに翻訳が存在しない場合、デフォルトロケールの翻訳を返し、デフォルトロケールにも存在しない場合はキーの値をそのまま返します。

```ts
export function t(key: TranslationKey, locale: Locale = defaultLocale): string {
    const current = translations[locale] as Partial<Record<TranslationKey, string>>;
    if (current[key] !== undefined) {
        return current[key]!;
    }
    const fallback = translations[defaultLocale] as Partial<Record<TranslationKey, string>>;
    return fallback[key] ?? key;
}
```

## defineConfig
`astro.config.ts`の`defineConfig`に、`i18n.config.ts`で設定した`locales`と`defaultLocale`を渡します。  
また、全言語のURLの取り扱いを統一するため、`prfixDefaultLocale`は`true`に設定します。

```ts
import { locales, defaultLocale } from '@i18n/i18n.config';

export default defineConfig({
    i18n: {
        locales,
        defaultLocale,
        routing: {
            prefixDefaultLocale: true
        }
    }
});
```

- `astro.config.ts`では、エイリアスを利用できないため、`i18n.config.ts`およびそこからインポートされるファイルは、エイリアスを使用できないことに注意が必要です。

## ユーティリティ関数
`@lib/locale/ts`に、ロケール関連のユーティリティ関数を記述します。

### isLocale()
`isLocale()`は、対象の文字列が有効なロケールであるかどうかを判定する関数です。

```ts
import { locales, type Locale } from '@i18n/i18n.config';
export function isLocale(value: string): value is Locale {
    return locales.includes(value as Locale);
}
```

### isTranslationKey()
`isTranslationKey`は、対象の文字列が有効な翻訳キーであるかどうかを判定する関数です。

```ts
import { translationKeys, type TranslationKey } from '@i18n/keys';
export function isTranslationKey(value: string): value is TranslationKey {
    return translationKeys.includes(value as TranslationKey);
}
```
