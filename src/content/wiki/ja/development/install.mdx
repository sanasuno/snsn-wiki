## Astro インストール
以下のコマンドで Astro をインストールします。

```bash
npm create astro@latest
```
- テンプレートは `Use minimal (empty) template` を選択、それ以外の質問はすべて `yes` を選択します。

## パッケージインストール

### Node.js
Node.js の型定義です。

```sh
npm install @types/node --save-dev
```

### sitemap
サイトマップを利用するためのインテグレーションです。

```sh
npx astro add sitemap
```

### mdx
mdx を利用するためのインテグレーションです。

```sh
npx astro add mdx
```

### Font Awesome
`Font Awesome` のパッケージです。

```sh
npm install --save @fortawesome/fontawesome-free
```

### PostCSS
PostCSS の `postcss-custom-media` と `postcss-preset-env` です。

```sh
npm install postcss-custom-media postcss-preset-env
```

### 画像生成ライブラリ
OGP 画像生成用に `satori` と `resvg-js` をインストールします。

```sh
npm install satori @resvg/resvg-js
```

```sh
npm i github-slugger
npm i -D @types/mdast
```

```sh
npm i satteri
```

```sh
npm install @astrojs/markdown-satteri
```
