## 環境構築
以下のコマンドで Astro をインストールします。

```bash
npm create astro@latest
```
- テンプレートは `Use minimal (empty) template` を選択、その他の質問はすべて `yes` を選択します。

## ディレクトリ構成
以下のようなディレクトリ構成を準備します。

```
./
├─ .gitignore
├─ astro.config.ts
├─ LICENSE
├─ package-lock.json
├─ package.json
├─ tsconfig.json
├─ public/
│   ├─ favicon.ico
│   └─ favicon.svg
└─ src/
    ├─ assets/
    ├─ components/
    ├─ content/
    │   └─ wiki/
    │       ├─ ja/
    │       │   └─ development/
    │       │       ├─ 00.mdx
    │       │       ├─ 01.mdx
    │       │       └─ ...
    │       └─ en/
    │       └─ eo/
    ├─ data/
    ├─ i18n/
    ├─ layouts/
    ├─ lib/
    ├─ pages/
    │   └─ [locale]/
    │       └─ index.astro
    │       └─ 404.astro
    │       └─ og/
    │           └─ [...slug].png.ts
    │       └─ wiki/
    │           └─ [...slug].astro
    ├─ scripts/
    ├─ styles/
    └─ types/

```

### エイリアス
`tsconfig.json` にエイリアスを設定します。

```json
{
    "extends": "astro/tsconfigs/strict",
    "include": [".astro/types.d.ts", "**/*"],
    "exclude": ["dist"],
    "compilerOptions": {
        "paths": {
            "@assets/*": ["./src/assets/*"],
            "@components/*": ["./src/components/*"],
            "@content/*": ["./src/content/*"],
            "@data/*": ["./src/data/*"],
            "@i18n/*": ["./src/i18n/*"],
            "@layouts/*": ["./src/layouts/*"],
            "@lib/*": ["./src/lib/*"],
            "@scripts/*": ["./src/scripts/*"],
            "@styles/*": ["./src/styles/*"],
            "@typeDefs/*": ["./src/types/*"]
        }
    }
}
```

## ライセンス
snsn-wiki は MIT ライセンスなので、`./LICENSE` に MIT ライセンスの全文を記述します。

## パッケージインストール

### Node.js
Node.js の型定義をインストールします。

```sh
npm install @types/node --save-dev
```

### PostCSS
PostCSS の `postcss-custom-media` と `postcss-preset-env` をインストールします。

```sh
npm install postcss-custom-media postcss-preset-env
```
