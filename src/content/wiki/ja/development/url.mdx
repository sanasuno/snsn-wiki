## 環境構築
以下のコマンドで Astro をインストールします。

```bash
npm create astro@latest
```
- テンプレートは `Use minimal (empty) template` を選択、その他の質問はすべて `yes` を選択します。

## ディレクトリ構成

### エイリアス
`tsconfig.json` にエイリアスを設定します。

```json
{
    "extends": "astro/tsconfigs/strict",
    "include": [".astro/types.d.ts", "**/*"],
    "exclude": ["dist"],
    "compilerOptions": {
        "paths": {
            "@assets/*": ["./src/assets/*"],
            "@components/*": ["./src/components/*"],
            "@content/*": ["./src/content/*"],
            "@data/*": ["./src/data/*"],
            "@i18n/*": ["./src/i18n/*"],
            "@layouts/*": ["./src/layouts/*"],
            "@lib/*": ["./src/lib/*"],
            "@scripts/*": ["./src/scripts/*"],
            "@styles/*": ["./src/styles/*"],
            "@typeDefs/*": ["./src/types/*"]
        }
    }
}
```

## astro.config.ts
`astro.config.ts` は、`Astro` のサイト設定を管理するファイルです。
ユーザーが誤った編集を行うとサイト全体に影響が及びうるため、
ユーザーの編集対象は別ファイルに記述し、それを `astro.config.ts` でインポートする、という形式をとります。

### URL管理
`Astro` の URL 管理には、`astro.config.ts` の `defineConfig` に
`site`（サイトのオリジン）と `base`（サブディレクトリ配置の配信パス）の値を設定する必要があります。

`./src/site.config.ts` に `url` と `basePath` を記述して `astro.config.ts` にインポートし、
検証と正規化をしてから `defineConfig` に渡します。

```ts
export const siteConfig = {
    url: 'https://example.com',
    basePath: '/'
} as const;
```

#### site
`siteConfig.url` が有効な URL であるかを `URL()` でチェックし、失敗したらエラーをスローします。
成功したら `string` 型に戻し、末尾の `/` を削除してから `site` に代入します。
- `try` ブロック内で `site` に代入するため、まず `let` で `site` を宣言しておきます。

```ts
let site: string;
try {
    site = new URL(siteConfig.url).toString().replace(/\/+$/, '');
} catch (error) {
    throw new Error(
        '[site.config] url is invalid',
        { cause: error }
    );
}
```

#### base
`siteConfig.basePath` が `/` で始まるかチェックし、失敗したらエラーをスローします。
成功したら、末尾の `/` を削除してから `base` に代入します。
なお、空文字列になった場合は `/` を代入します。

```ts
if (!siteConfig.basePath.startsWith('/')) {
    throw new Error(
        '[site.config] basePath must start with "/"'
    );
}
const base = siteConfig.basePath.replace(/\/+$/, '') || '/';
```

#### defineConfig
設定した `site` と `base` を `defineConfig` に渡します。
また、 `trailingSlash: 'always'` を設定し、URL の末尾に `/` が付くようにします。

```ts
export default defineConfig({
    site,
    base,
    trailingSlash: 'always',
})
```
