`@i18n/keys.ts` および `@i18n/keys.custom.ts` は翻訳キーの定義ファイルです。システム標準の翻訳キーは `keys.ts` に、ユーザー編集用の翻訳キーは `keys.custom.ts` に記述します。
- `snsn-wiki` 本体のアップデートによってユーザー独自の翻訳を上書きしないように分離しています。

## customKeys
ユーザーが独自に定義する翻訳キー配列です。`as const` で型情報として保持しています。
- `site.title` および `site.description` は必須です。

## CustomKey
ユーザー編集用翻訳キーの型です。ユーザー編集用翻訳ファイルの型チェックに使用します。

```ts
export type CustomKey = typeof customKeys[number];
```

## structuralKeys
システム標準の翻訳キー配列です。`as const` で型情報として保持しています。

## translationKeys
`structuralKeys` と `customKeys` を結合した翻訳キー一覧の配列です。

```ts
export const translationKeys = [...structuralKeys, ...customKeys] as const;
```

## TranslationKey
翻訳キーの型です。翻訳ファイルの型チェックに使用します。

```ts
export type TranslationKey = typeof translationKeys[number];
```
