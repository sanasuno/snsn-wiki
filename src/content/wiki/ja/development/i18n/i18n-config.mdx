`@18n/i18n.config.ts` は、ロケール登録とデフォルトロケールの設定を記述するファイルです。

## インポート
[[翻訳ファイル]]をインポートします。

```ts
import { ja } from './ja';
import { en } from './en';
import { eo } from './eo';
```

## translations
インポートした翻訳ファイルをすべてまとめたオブジェクトです。`as const` で読み取り専用にしています。

```ts
export const translations = {
    ja,
    en,
    eo,
} as const;
```

### defaultLocale
翻訳やページ遷移のフォールバックとして使われるロケールです。
- `satisfies keyof typeof translations` で登録済みのロケールかどうかを検証します。

```ts
export const defaultLocale = 'ja' satisfies keyof typeof translations;
```
