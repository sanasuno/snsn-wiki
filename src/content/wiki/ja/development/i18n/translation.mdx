## i18nについて
i18n（国際化）対応を実装します。ここでは、ビルド時に実行されるサーバーサイド翻訳の実装をします。

記述するのは以下のファイルです。
- `@i18n/i18n.config.ts` ：翻訳ロジックの中心となる設定ファイル
- `@i18n/keys.ts`, `@i18n/keys.custom.ts` ：翻訳キーのスキーマ定義ファイル
- `@i18n/ja.ts`, `@i18n/ja.custom.ts`, ... ：各ロケールの翻訳を記述する辞書ファイル
- `@lib/i18n.ts` ：i18n 関連のユーティリティ関数

## 翻訳辞書ファイル
また、具体的な翻訳を記述する翻訳辞書ファイルも、`ja.ts` と `ja.custom.ts` のように分離して記述し、
対応する翻訳キー型で型チェックします。  
翻訳辞書は `[key]: [value]` の形式で定義され、それらを各言語ごとにまとめて出力します。

## i18n.config.ts
`i18n.config.ts` は、i18n関連の中心となるファイルです。
各言語の翻訳辞書から型やロケール一覧などを派生的に定義します。

### 翻訳キー
i18n 関連のインポートをこのファイルから統一して行えるように、
翻訳キーの型である `TranslationKey` 型を `keys.ts` からインポートして、そのままエクスポートします。

```ts
import type { TranslationKey } from './keys';
export type { TranslationKey };
```

### 翻訳辞書ファイルのインポート
`i18n` ディレクトリ配下にある翻訳辞書ファイルをインポートし、
すべてまとめて `translations` オブジェクトに格納します。  
ロケールを追加・削除するときは、ここを編集します。

```ts
import { en } from './en';
import { eo } from './eo';
import { ja } from './ja';
export const translations = {
    en,
    eo,
    ja
} as const;
```

### ロケール型
`translations` のキーを、ロケール型 `Locale` として定義します。

```ts
export type Locale = keyof typeof translations;
```

### 利用可能なロケール一覧
`translations` のキー配列を、利用可能なロケール一覧 `locales` として定義します。

```ts
export const locales = Object.keys(translations) as Locale[];
```

### デフォルトロケール
翻訳やページ遷移のフォールバックとして使われるデフォルトロケール `defaultLocale` を決定します。
- デフォルトロケールは `Locale` 型の要素である必要があります。

```ts
export const defaultLocale = 'ja' satisfies Locale;
```

### t()
メインの翻訳関数です。与えられた翻訳キーとロケールから、翻訳された文字列を取得します。
- `locale` パラメータを省略した場合は `defaultLocale` が使用されます。
- 指定されたロケールに翻訳が存在しない場合、デフォルトロケールの翻訳を返します。
- デフォルトロケールにも翻訳が存在しない場合は、キーの値をそのまま返します。

```ts
export function t(key: TranslationKey, locale: Locale = defaultLocale): string {
    const current = translations[locale] as Partial<Record<TranslationKey, string>>;
    if (current[key] !== undefined) {
        return current[key]!;
    }
    const fallback = translations[defaultLocale] as Partial<Record<TranslationKey, string>>;
    return fallback[key] ?? key;
}
```

## defineConfig
`astro.config.ts` の `defineConfig` に `i18n.config.ts` で設定した `locales` と `defaultLocale` を渡します。

また、URLでの取り扱いを全言語で統一するため、 `prefixDefaultLocale` は `true` に設定します。

- `astro.config.ts` ではエイリアスを利用できないため、
`i18n.config.ts` およびそこからインポートされるファイルでもエイリアスを使用できません。

```ts
import { t, locales, defaultLocale } from './src/i18n/i18n.config';

export default defineConfig({
    i18n: {
        locales,
        defaultLocale,
        routing: {
            prefixDefaultLocale: true
        }
    }
});
```

## ユーティリティ関数
`@lib/i18n.ts` にロケール関連のユーティリティ関数を記述します。

### isLocale()
対象の文字列が有効なロケールかどうかを判定する関数です。
引数が `locales` 配列に含まれているかをチェックします。

```ts
import { locales, type Locale } from '@i18n/i18n.config';
export function isLocale(value: string): value is Locale {
    return locales.includes(value as Locale);
}
```

### isTranslationKey()
対象の文字列が有効な翻訳キーかどうかを判定する関数です。
引数が `translationKeys` 配列に含まれているかをチェックします。

```ts
import { translationKeys, type TranslationKey } from '@i18n/keys';
export function isTranslationKey(value: string): value is TranslationKey {
    return translationKeys.includes(value as TranslationKey);
}
```
