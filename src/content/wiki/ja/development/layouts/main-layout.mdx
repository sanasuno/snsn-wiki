`@layouts/MainLayout.astro` は、レイアウトの全体構造を記述するファイルです。主に `<head>` 部分を記述し、 `<body>` 部分の要素は個別のレイアウトコンポーネントに切り出します。

## フロントマター
必要なレイアウトコンポーネントや CSS をフロントマター内に記述してインポートします。

### レイアウトコンポーネント

```ts
import Header from '@layouts/Header.astro';
import Sidebar from '@layouts/Sidebar.astro';
import MainContent from '@layouts/MainContent.astro';
import Footer from '@layouts/Footer.astro';
import Toc from '@layouts/Toc.astro';
import MiniGraph from '@layouts/MiniGraph.astro';
```

### Font Awesome
`Font Awesome` の CSS です。

```ts
import '@fortawesome/fontawesome-free/css/all.min.css';
```

### CSS
各レイアウトコンポーネント用の CSS です。

```ts
import '@styles/theme.css';
import '@styles/base.css';
import '@styles/layout.css';
import '@styles/header.css';
import '@styles/sidebar.css';
import '@styles/main-content.css';
import '@styles/subpanel.css';
import '@styles/footer.css';
import '@styles/custom.css';
```

## \<head\>
### 文字コード
文字コードを設定します。

```astro
<meta charset="utf-8">
```

### 表示領域
表示領域を設定します。表示領域を画面幅に合わせ、初期ズーム倍率を 1.0 倍に設定し、セーフエリアに対応します。

```astro
        <meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover">
```

### タイトルと説明
ページのタイトルと説明を記述します。
- タイトルは個別ページのタイトルとサイトタイトルを併記します。
- 説明は個別ページにあればそれを、なければサイト全体の説明を使用します。
- サイト全体のタイトル及び説明はロケール依存です。

```astro
---
interface Props {
    title: string;
    description?: string;
    locale?: Locale;
}
const { title, description, locale = defaultLocale } = Astro.props;
const siteTitle = t('site.title', locale);
const siteDescription = t('site.description', locale);
const pageTitle = `${title} | ${siteTitle}`;
const pageDescription = description ?? siteDescription;
---
<title>{pageTitle}</title>
<meta name="description" content={pageDescription} />
```

### ジェネレーター
ジェネレーターを記述します。

```astro
<meta name="generator" content="snsn-wiki" />
```

### ファビコン
`ico` 形式と `svg` 形式の2種類で記述します。
- `svg` 形式が優先的に表示されます。
- `svg` 形式が利用できない環境では `ico` 形式が表示されます。

```astro
<link rel="icon" href={new URL(`${baseUrl}favicon.ico`, Astro.url).href} sizes="48x48" />
<link rel="icon" href={new URL(`${baseUrl}favicon.svg`, Astro.url).href} type="image/svg+xml" />
```

### サイトマップ
`sitemap` インテグレーションを使用して生成されたサイトマップへのリンクを記述します。

```astro
<link rel="sitemap" href={new URL(`${baseUrl}sitemap-index.xml`, Astro.url).href} />
```

### カノニカルURL
カノニカルURLを記述します。

```astro
---
const currentPath = getCurrentPath(Astro.url);
const canonicalUrl = new URL(currentPath, Astro.url).href;
---
<link rel="canonical" href={canonicalUrl} />
```

### 代替リンク
代替リンクを記述します。デフォルトロケールのリンクをフォールバックとして指定します。

```astro
---
const defaultAlternateLink = alternateLinks.find(link => link.locale === defaultLocale);
---
{defaultAlternateLink && <link rel="alternate" href={new URL(defaultAlternateLink.href, Astro.url).href} hreflang="x-default" />}
{alternateLinks.map(link => <link rel="alternate" href={new URL(link.href, Astro.url).href} hreflang={link.locale} />)}
```

### テーマ初期化スクリプト

```astro
<script is:inline>
    (function() {
        let savedTheme = null;
        try { savedTheme = localStorage.getItem('theme'); } catch (e) {}
        if (savedTheme) {
            document.documentElement.setAttribute('data-theme', savedTheme);
        } else {
            const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
            document.documentElement.setAttribute('data-theme', prefersDark ? 'dark' : 'light');
        }
    })();
</script>
```

## \<body\>
レイアウトコンポーネントを配置します。

```astro
    <body>
        <Header
            locale={locale}
        />
        <div class={`layout${showSubpanel ? '' : ' no-subpanel'}`}>
            <Sidebar
                locale={locale}
            />
            <MainContent
                title={title}
                locale={locale}
                type={type}
                tags={tags}
                date={date}
                updated={updated}
                id={id}
                isSubpage={isSubpage}
                isFallback={isFallback}
                fallbackLocale={fallbackLocale}
            >
                <slot />
            </MainContent>
            {showSubpanel && (
                <>
                    <aside class="subpanel" id="subpanel">
                        <Toc
                            locale={locale}
                            headings={headings}
                        />
                        <MiniGraph
                            locale={locale}
                        />
                    </aside>
                    <button type="button" class="subpanel-drawer-button" id="subpanel-drawer-button" aria-label={t('subpanel.open', locale)} aria-controls="subpanel" aria-expanded="false">
                        <i class="fas fa-list-ul" aria-hidden="true"></i>
                    </button>
                </>
            )}
        </div>
        <Footer
            locale={locale}
        />
        <script>
            import '@scripts/main';
        </script>
    </body>
```
