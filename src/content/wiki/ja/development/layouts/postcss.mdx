`PostCSS` を導入することで、自由にカスタムメディアを設定し、レイアウトの各部位の幅を自由にカスタマイズできます。

## layout.tokens.json
各部位の画面幅トークンを定義するファイルです。

```json
{
    "contentMaxWidth": 1200,
    "contentMinWidth": 800,
    "sidebarWidth": 280,
    "subpanelWidth": 240,
    "headerLabelBreakpoint": 1024,
    "mobileBreakpoint": 768,
    "contentPadding": {
        "wide": 48,
        "medium": 24,
        "narrow": 16
    }
}
```

- `contentMaxWidth` : メインコンテンツの最大幅です。
- `contentMinWidth` : メインコンテンツの最小幅です。
- `sidebarWidth` : サイドバーの幅です。
- `subpanelWidth` : サブパネルの幅です。
- `headerLabelBreakpoint` : ヘッダーナビゲーションのラベルのブレークポイントです。
- `mobileBreakpoint` : モバイル環境のブレークポイントです。
- `contentPadding` : メインコンテンツのパディングです。3段階設定します。

## postcss.config.cjs
`postcss.config.cjs` は、 `PostCSS` の設定ファイルです。ブラウザの画面幅に応じたカラム表示のカスタムメディアを計算します。

### tokens
トークンをインポートします。

```cjs
const tokens = require('./src/layout.tokens.json');
```

### px
数値を px 単位に変換するヘルパーです。

```cjs
const px = (n) => `${n}px`;
```

### subpanelAt
3カラム（sidebar + 本文 + subpanel）が収まる最小幅です。

```cjs
const subpanelAt =
    tokens.sidebarWidth +
    tokens.subpanelWidth +
    tokens.contentMinWidth +
    tokens.contentPadding.wide * 2;
```

### noSubpanelAt
サブパネルなしのページで wide padding が収まる最小幅です。

```cjs
const noSubpanelAt =
    tokens.sidebarWidth +
    tokens.contentMinWidth +
    tokens.contentPadding.wide * 2;
```

### layoutTokens
全 CSS ファイルに `@custom-media` を、 `theme.css` に `:root` の寸法変数を注入する独自プラグインです。

#### `@custom-media` 注入
`root.prepend` で全 CSS ファイルにカスタムメディア定義を注入します。

```cjs
root.prepend(
    new AtRule({ name: 'custom-media', params: `--subpanel-collapsed (width < ${px(subpanelAt)})` }),
    new AtRule({ name: 'custom-media', params: `--no-subpanel-collapsed (width < ${px(noSubpanelAt)})`}),
    new AtRule({ name: 'custom-media', params: `--sidebar-collapsed (width <= ${px(tokens.mobileBreakpoint)})` }),
    new AtRule({ name: 'custom-media', params: `--header-compact (width <= ${px(tokens.headerLabelBreakpoint)})` })
);
```

- `--subpanel-collapsed` : サブパネルが折りたたまれていることを示すカスタムメディアです。
- `--no-subpanel-collapsed` : サブパネルが折りたたまれていないことを示すカスタムメディアです。
- `--sidebar-collapsed` : サイドバーが折りたたまれていることを示すカスタムメディアです。
- `--header-compact` : ヘッダーナビゲーションのラベルが折りたたまれていることを示すカスタムメディアです。

#### `:root` の寸法変数注入
`theme.css` に `:root` の寸法変数を注入します。

```cjs
if (/theme\.css$/.test(root.source?.input.file ?? '')) {
    const decls = {
        '--content-max-width': px(tokens.contentMaxWidth),
        '--sidebar-width': px(tokens.sidebarWidth),
        '--subpanel-width': px(tokens.subpanelWidth),
        '--subpanel-breakpoint': px(subpanelAt),
        '--mobile-breakpoint': px(tokens.mobileBreakpoint),
        '--content-padding-wide': px(tokens.contentPadding.wide),
        '--content-padding-medium': px(tokens.contentPadding.medium),
        '--content-padding-narrow': px(tokens.contentPadding.narrow),
    };
    const rule = new Rule({ selector: ':root', source: root.source });
    for (const [prop, value] of Object.entries(decls)) {
        rule.append(new Declaration({ prop, value, source: root.source }));
    }
    root.prepend(rule);
}
```
