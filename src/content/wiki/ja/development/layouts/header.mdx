### サイドバー切り替えスクリプト
サイドバー切り替え用のスクリプトを `@scripts/sidebar.ts` に記述します。

### setSidebarToggleBtnState()
サイドバー切り替えボタンの状態を設定する関数です。
ボタン要素とサイドバーの開閉状態を受け取り、`aria-expanded` 属性とアイコンを切り替えます。

```ts
function setSidebarToggleBtnState(btn: HTMLButtonElement, isOpen: boolean) {
    btn.setAttribute('aria-expanded', isOpen.toString());
    const icon = btn.querySelector('i');
    if (icon) {
        icon.classList.toggle('fa-bars', !isOpen);
        icon.classList.toggle('fa-xmark', isOpen);
    }
}
```

### sidebarToggle()
サイドバー切り替えボタンの動作を制御する関数です。
ボタンをクリックするとサイドバーの開閉状態を切り替え、`aria-expanded` 属性とアイコンを更新します。
また、サイドバーが開いている状態で、サイドバー外をクリックするとサイドバーを閉じます。

まず、サイドバーと切り替えボタンの要素を取得します。存在しなければ処理を終了します。

```ts
const sidebar = document.getElementById('sidebar');
if (!sidebar) return;
const sidebarToggleBtn = document.getElementById('sidebar-toggle');
if (!(sidebarToggleBtn instanceof HTMLButtonElement)) return;
```

`dataset.initialized` を使って、すでに初期化済みかどうかを判定します。

```ts
if (sidebarToggleBtn.dataset.initialized === 'true') return;
sidebarToggleBtn.dataset.initialized = 'true';
```

サイドバーがすでに開いている状態でページが読み込まれた場合、切り替えボタンの状態を開いた状態に更新します。

```ts
const initialOpen = sidebar.classList.contains('open');
setSidebarToggleBtnState(sidebarToggleBtn, initialOpen);
```

ボタンをクリックしたときのイベントリスナーを追加します。
サイドバーの開閉状態を切り替え、切り替えボタンの状態も更新します。

```ts
sidebarToggleBtn.addEventListener('click', (e) => {
    e.stopPropagation();
    sidebar.classList.toggle('open');
    const isOpen = sidebar.classList.contains('open');
    setSidebarToggleBtnState(sidebarToggleBtn, isOpen);
});
```

ドキュメント全体にクリックイベントリスナーを追加し、
サイドバー外・ボタン外をクリックしたとき、
サイドバーが開いている状態ならサイドバーを閉じます。

```ts
document.addEventListener('click', (e) => {
    if (
        e.target instanceof Element &&
        sidebar.classList.contains('open') &&
        !sidebar.contains(e.target) &&
        !sidebarToggleBtn.contains(e.target)
    ) {
        sidebar.classList.remove('open');
        setSidebarToggleBtnState(sidebarToggleBtn, false);
    }
});
```

画面幅が 768px を超えた場合、サイドバーを閉じ、切り替えボタンの状態も閉じた状態に更新します。

```ts
window.matchMedia('(width <= 768px)').addEventListener('change', (e) => {
    if (!e.matches) {
        sidebar.classList.remove('open');
        setSidebarToggleBtnState(sidebarToggleBtn, false);
    }
});
```

### テーマ初期化
`MainLayout.astro`内に、インラインスクリプトでテーマ初期化処理を記述します。  
テーマの初期値は、ユーザーが保存したテーマ（`localStorage`）を優先し、存在しない場合はブラウザの設定（`prefers-color-scheme`）から決定します。

```astro
<script is:inline>
    (function() {
        let savedTheme = null;
        try { savedTheme = localStorage.getItem('theme'); } catch (e) {}
        if (savedTheme) {
            document.documentElement.setAttribute('data-theme', savedTheme);
        } else {
            const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
            document.documentElement.setAttribute('data-theme', prefersDark ? 'dark' : 'light');
        }
    })();
</script>
```

### ローカルストレージ操作スクリプト
`@scripts/localStorage.ts` に、ローカルストレージ操作用の関数を記述します。

#### setLocalStorage
ローカルストレージに値を保存する関数です。

```ts
export function setLocalStorage(key: string, value: string): boolean {
    try {
        localStorage.setItem(key, value);
        return true;
    } catch (error) {
        console.error(`Failed to set localStorage key: ${key}`, error);
        return false;
    }
}
```

#### getLocalStorage
ローカルストレージから値を取得する関数です。

```ts
export function getLocalStorage(key: string): string | null {
    try {
        return localStorage.getItem(key);
    } catch (error) {
        console.error(`Failed to get localStorage key: ${key}`, error);
        return null;
    }
}
```

### テーマ制御スクリプト
テーマ切り替えボタンの動作を制御するスクリプトを `@scripts/theme.ts` に記述します。

ボタンのクリックイベントで、現在のテーマを取得し、次のテーマに切り替えます。

```ts
import { setLocalStorage } from "@scripts/localStorage";
export function themeToggle() {
    const btn = document.getElementById('theme-toggle')
    if (!btn) return;

    btn.addEventListener('click', () => {
        const currentTheme = document.documentElement.getAttribute('data-theme');
        const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
        const isDark = currentTheme === 'dark' || (!currentTheme && prefersDark);
        const nextTheme = isDark ? 'light' : 'dark';
        document.documentElement.setAttribute('data-theme', nextTheme);
        setLocalStorage('theme', nextTheme);
    })
}
```

`@scripts/main.ts` から `themeToggle` 関数を呼び出します。

```ts
import { themeToggle } from "@scripts/theme";
themeToggle();
```

### 言語切り替えスクリプト
`@scripts/languageSwitch.ts` に、言語切り替え用のスクリプトを記述します。

#### resolveLocale()
HTMLの `lang` 属性からロケールを解決する関数です。

与えられた `htmlLang` が有効なロケールであればそれを返し、そうでなければローカルストレージに保存されたロケールを確認します。
それも存在しなければ、デフォルトのロケールを返します。

```ts
function resolveLocale(htmlLang: string): Locale {
    if (isLocale(htmlLang)) {
        return htmlLang;
    }
    const storedLocale = getLocalStorage('locale');
    if (storedLocale && isLocale(storedLocale)) {
        return storedLocale;
    }
    return defaultLocale;
}
```

#### updateLanguageSwitcher()

言語切り替えボタンの状態を更新する関数です。

`language-list` の `select` 要素を取得し、現在のロケールに合わせて選択状態を更新します。

```ts
function updateLanguageSwitcher(): void {
    const selected = document.getElementById('language-list') as HTMLSelectElement | null;
    if (!selected) return;

    const locale = document.documentElement.lang || getLocalStorage('locale');
    if (locale) {
        selected.value = locale;
    }
}
```

#### handlers
翻訳ハンドラの定義です。`data-i18n` 属性を持つ要素に対して、翻訳された文字列を設定します。

```ts
const handlers: Record<string, (el: Element, text: string) => void> = {
    'data-i18n': (el, text) => {
        el.textContent = text;
    }
};
```

#### applyTranslations()

翻訳を適用する関数です。

翻訳ハンドラをループし、`data-i18n` 属性を持つ要素に対して翻訳を適用します。

```ts
function applyTranslations(): void {
    const locale = getLocalStorage('locale');
    if (!locale || !isLocale(locale)) return;

    Object.entries(handlers).forEach(([attr, handler]) => {
        const elements = document.querySelectorAll(`[${attr}]`);
        elements.forEach((el) => {
            const key = el.getAttribute(attr);
            if (key && isTranslationKey(key)) {
                handler(el, t(key, locale));
            }
        });
    });
}
```

#### refreshI18nUI()

i18n UI を更新する関数です。

言語スイッチャーの状態を更新し、翻訳を適用します。

```ts
function refreshI18nUI(): void {
    updateLanguageSwitcher();
    applyTranslations();
}
```

#### initI18n()

i18n を初期化する関数です。

まず、初期化済みかどうかを判定し、すでに初期化済みであれば処理を終了します。

HTML の `lang` 属性からロケールを解決し、HTML の `lang` 属性とローカルストレージを同期します。
もし、ページが読み込み中であれば `DOMContentLoaded` イベントで `refreshI18nUI()` を、読み込みが完了していれば、すぐに `refreshI18nUI()` を呼び出します。

```ts
let i18nInitialized = false;
export function initI18n(): void {
    if (i18nInitialized) return;
    i18nInitialized = true;

    const htmlLang = document.documentElement.dataset.lang ?? '';
    const resolvedLocale = resolveLocale(htmlLang);

    document.documentElement.lang = resolvedLocale;
    setLocalStorage('locale', resolvedLocale);

    if (document.readyState === 'loading') {
        document.addEventListener('DOMContentLoaded', refreshI18nUI, { once: true });
    } else {
        refreshI18nUI();
    }
}
```

#### languageSwitch()
言語スイッチャーのイベントを設定する関数です。

まず、`language-list` の `select` 要素を取得し、存在しなければ処理を終了します。
また、二重登録を防ぐため、`dataset.languageSwitchInitialized` を使って初期化済みかどうかを判定します。

言語が切り替えられたとき、選択されたロケールを検証し、ローカルストレージに保存します。
その後、`hreflang` リンクを使って対応する言語ページにナビゲートします。
もし、対応する言語ページが存在しなければ、`x-default` のリンクにフォールバックし、それも存在しなければページをリロードします。

```ts
export function languageSwitch(): void {
    const languageList = document.getElementById('language-list') as HTMLSelectElement | null;
    if (!languageList) return;

    if (languageList.dataset.languageSwitchInitialized === 'true') return;
    languageList.dataset.languageSwitchInitialized = 'true';

    languageList.addEventListener('change', () => {
        const selectedLocale = languageList.value;

        if (!isLocale(selectedLocale)) {
            console.warn(`Invalid locale: ${selectedLocale}`);
            return;
        }

        setLocalStorage('locale', selectedLocale);

        const altLink = document.querySelector<HTMLLinkElement>(
            `link[rel="alternate"][hreflang="${selectedLocale}"]`
        );
        if (altLink?.href) {
            window.location.href = altLink.href;
            return;
        }

        const defaultLocaleLink = document.querySelector<HTMLLinkElement>(
            'link[rel="alternate"][hreflang="x-default"]'
        );
        if (defaultLocaleLink?.href) {
            window.location.href = defaultLocaleLink.href;
            return;
        }

        window.location.reload();
    });
}
```
