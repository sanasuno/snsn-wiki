## OGP 画像について
各ページごとに OGP 画像を生成します。生成には `satori` と `resvg-js` を用います。
画像には、サイト名、各ページのタイトルと説明、カテゴリを記述します。

## カテゴリ
カテゴリはウィキページのみ設定します。各ページの配置パスをもとにカテゴリを導出します。

カテゴリ関連のユーティリティ関数は `@lib/category.ts` に記述します。

### getCategory()
ページ ID からカテゴリ配列を取得する関数です。

ページ ID を `/` で分割し、最後の1つ（ページのファイル名）を除いた部分をカテゴリとして返します。

`isSubPage = "true"` が設定されている場合、最後から2番目の要素も親ページのファイル名とみなすため、
最後の2つを除いた部分を返します。

```ts
export function getCategory(pageId: string, isSubpage: boolean = false): string[] {
    const parts = pageId.split('/');
    if (isSubpage) {
        return parts.slice(1, -2);
    } else {
        return parts.slice(1, -1);
    }
}
```

### getCategoryString()
ページ ID からカテゴリを一つの文字列として取得する関数です。

```ts
export function getCategoryString(pageId: string, isSubpage: boolean = false): string {
    const category = getCategory(pageId, isSubpage);
    return category.join('/');
}
```

### getTranslatedCategory()
ページ ID から翻訳されたカテゴリ名を取得する関数です。

カテゴリ配列を `.` で結合し、先頭に `category.` をつけた文字列を翻訳キーとして使用します。

```ts
export function getTranslatedCategory(pageId: string, locale: Locale, isSubPage: boolean = false ): string {
    const category = getCategory(pageId, isSubPage);
    if (category.length === 0 || (category.length === 1 && category[0] === '')) return '';
    
    const key = `category.${category.join('.')}` as TranslationKey;
    if (!isTranslationKey(key)) return '';
    
    return t(key, locale);
}
```

### フォントキャッシュ
使用するフォントのキャッシュを用意します。

```ts
const FONT_DIR = path.resolve(process.cwd(), 'src/assets/fonts');

let fontsCache: { name: string; data: Buffer; weight: FontWeight; style: 'normal' }[] | null = null;
function loadFonts() {
    if (fontsCache) return fontsCache;
    fontsCache = [
        { name: 'Noto Sans', data: readFileSync(path.join(FONT_DIR, 'NotoSans-Regular.ttf')), weight: 400, style: 'normal' },
        { name: 'Noto Sans', data: readFileSync(path.join(FONT_DIR, 'NotoSans-Bold.ttf')), weight: 700, style: 'normal' },
        { name: 'Noto Sans JP', data: readFileSync(path.join(FONT_DIR, 'NotoSansJP-Regular.ttf')), weight: 400, style: 'normal' },
        { name: 'Noto Sans JP', data: readFileSync(path.join(FONT_DIR, 'NotoSansJP-Bold.ttf')), weight: 700, style: 'normal' },
        
    ];
    return fontsCache;
}
```

### renderOgImage()
OGP 画像のレンダリングを実行する関数です。ページタイトル、説明、カテゴリ、サイト名を描画します。

```ts
export async function renderOgImage({ title, description, category, siteName }: OgImageParams): Promise<Buffer> {
    const width = 1200;
    const height = 630;

    const vnode = {
        type: 'div',
        props: {
            style: {
                width: '100%',
                height: '100%',
                display: 'flex',
                flexDirection: 'column',
                justifyContent: 'space-between',
                padding: '64px',
                background: '#0f1115',
                color: '#f5f5f5',
                fontFamily: 'Noto Sans, Noto Sans JP',
            },
            children: [
                {
                    type: 'div',
                    props: {
                        style: {
                            fontSize: 28,
                            opacity: 0.7
                        },
                        children: siteName
                    }
                },
                {
                    type: 'div',
                    props: {
                        style: {
                            display: 'flex',
                            flexDirection: 'column',
                        },
                        children: [
                            {
                                type: 'div',
                                props: {
                                    style: {
                                        fontSize: 56,
                                        fontWeight: 700,
                                        lineHeight: 1.3
                                    },
                                    children: title,
                                },
                            },
                            description
                                ? {
                                    type: 'div',
                                    props: {
                                        style: {
                                            fontSize: 30,
                                            opacity: 0.8,
                                            marginTop: 16
                                        },
                                        children: description
                                    }
                                }
                                : null,
                        ].filter(Boolean)
                    }
                },
                category
                    ? {
                        type: 'div',
                        props: {
                            style: {
                                display: 'flex',
                                flexWrap: 'wrap',
                            },
                            children: {
                                type: 'div',
                                props: {
                                    style: {
                                        fontSize: 24,
                                        padding: '6px 16px',
                                        borderRadius: 999,
                                        border: '1px solid rgba(245,245,245,0.4)',
                                    },
                                    children: category,
                                },
                            },
                        },
                    }
                    : null,
            ].filter(Boolean),
        },
    };

    const svg = await satori(vnode as any, { width, height, fonts: loadFonts() });
    const resvg = new Resvg(svg, { fitTo: { mode: 'width', value: width} });
    return resvg.render().asPng();
}
```

## 画像配信エンドポイント
`./src/pages/[locale]/og/[...slug].png.ts` に、画像配信エンドポイントを記述します。

### getStaticPaths()
各ページ用の OGP 画像を配置する URL を組み立てます。また、画像のレンダーに必要な各種情報も `props` として出力します。

ウィキページでは `resolveWikiPages()` 関数を用いてページ情報を格納します。

それ以外のページでは、ロケールごとにサイト全体の情報を記した同じものを使用し、 `slug: 'index'` として出力します。

```ts
export const getStaticPaths = (async () => {
    const resolvedPages = await resolveWikiPages();
    const wikiPaths = resolvedPages.map(({ locale, slug, page }) => {
        const category = getTranslatedCategory(page.id, locale, page.data.isSubPage);
        return {
            params: {
                locale,
                slug: slug === '' ? 'wiki' : `wiki/${slug}`,
            },
            props: {
                title: page.data.title,
                description: page.data.description,
                category,
                siteName: t('site.title', locale),
            },
        };
    });
    const fallbackPaths = locales.map((locale) => ({
        params: {
            locale,
            slug: 'index',
        },
        props: {
            title: t('site.title', locale),
            description: t('site.description', locale),
            category: undefined,
            siteName: t('site.title', locale),
        },
    }));
    return [...wikiPaths, ...fallbackPaths];
}) satisfies GetStaticPaths;
```

### GET
OGP 画像をレンダリングして返します。

```ts
export const GET: APIRoute = async ({ props }) => {
    const { title, description, category, siteName } = props as { title: string; description?: string; category?: string; siteName: string; };
    const png = await renderOgImage({ title, description, category, siteName });
    return new Response(new Uint8Array(png), {
        headers: {
            'Content-Type': 'image/png',
            'Cache-Control': 'public, max-age=31536000, immutable',
        },
    });
};
```
