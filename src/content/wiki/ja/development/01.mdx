## 環境構築
以下のコマンドでAstroをインストールします。

```bash
npm create astro@latest
```
- テンプレートは `Use minimal (empty) template` を選択、その他の質問はすべて `yes` を選択します。

### エイリアス
`tsconfig.json`にエイリアスを設定します。

```json
{
    "extends": "astro/tsconfigs/strict",
    "include": [".astro/types.d.ts", "**/*"],
    "exclude": ["dist"],
    "compilerOptions": {
        "paths": {
            "@assets/*": ["./src/assets/*"],
            "@components/*": ["./src/components/*"],
            "@content/*": ["./src/content/*"],
            "@data/*": ["./src/data/*"],
            "@i18n/*": ["./src/i18n/*"],
            "@layouts/*": ["./src/layouts/*"],
            "@lib/*": ["./src/lib/*"],
            "@scripts/*": ["./src/scripts/*"],
            "@styles/*": ["./src/styles/*"],
            "@typeDefs/*": ["./src/types/*"]
        }
    }
}
```

## URL管理
Astroでは、`astro.config.ts`に`site`（サイトのオリジン）と`base`（サブディレクトリに配置する場合の配信パス）の値を設定することで、サイトのURLを管理します。  
`src/site.config.ts`に、`siteConfig`として`url`と`basePath`を設定し、検証と正規化をしてから`astro.config.ts`の`defineConfig`に渡します。

```ts
export const siteConfig = {
    url: 'https://example.com', // 本番サイトのオリジン
    basePath: '/' // 配信パス（サブディレクトリ配信する場合記述、不要なら'/'）
} as const;
```

### site
`siteConfig`から`url`を取得し、正規化してから`site`に代入します。

```ts
import { siteConfig } from './src/site.config';

let site: string;
try {
    site = new URL(siteConfig.url).toString().replace(/\/+$/, '');
} catch (error) {
    throw new Error(
        '[site.config] url is an invalid URL',
        { cause: error }
    );
}
```

- まず、`siteConfig.url`を`new URL()`でURLオブジェクトに変換できるかチェックします。  
- 変換に成功したら、`toString()`で`string`型に戻してから、末尾の`/`を削除して、`site`変数に代入します。  
- 変換に失敗した場合、`siteConfig.url`が有効なURLでないとみなして、エラーを投げます。  

### base
`siteConfig`から`basePath`を取得し、正規化してから`base`に代入します。

```ts
import { siteConfig } from './src/site.config';

if (!siteConfig.basePath.startsWith('/')) {
    throw new Error(
        '[site.config] basePath must start with "/"'
    );
}
const base = siteConfig.basePath.replace(/\/+$/, '') || '/';
```
- `basePath`が`/`で始まるかチェックし、`/`で始まらない場合はエラーを投げます。  
- `basePath`の末尾の`/`を削除して、`base`変数に代入します。削除した結果、空文字列になった場合、`/`を代入します。

### defineConfig
設定した`site`と`base`を`defineConfig`に渡します。

```ts
export default defineConfig({
    site,
    base,
})
```
