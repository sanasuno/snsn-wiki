## 環境構築
以下のコマンドで Astro をインストールします。

```bash
npm create astro@latest
```
- テンプレートは `Use minimal (empty) template` を選択、その他の質問はすべて `yes` を選択します。

## ディレクトリ構成

### エイリアス
`tsconfig.json` にエイリアスを設定します。

```json
{
    "extends": "astro/tsconfigs/strict",
    "include": [".astro/types.d.ts", "**/*"],
    "exclude": ["dist"],
    "compilerOptions": {
        "paths": {
            "@assets/*": ["./src/assets/*"],
            "@components/*": ["./src/components/*"],
            "@content/*": ["./src/content/*"],
            "@data/*": ["./src/data/*"],
            "@i18n/*": ["./src/i18n/*"],
            "@layouts/*": ["./src/layouts/*"],
            "@lib/*": ["./src/lib/*"],
            "@scripts/*": ["./src/scripts/*"],
            "@styles/*": ["./src/styles/*"],
            "@typeDefs/*": ["./src/types/*"]
        }
    }
}
```

## URL管理
Astro では、`astro.config.ts` に `site`（サイトのオリジン）と `base`（サブディレクトリに配置する場合の配信パス）の値を設定することで、サイトのURLを管理します。ただし、これらの値はユーザーが編集する対象なので、安全のために別ファイル（`./src/site.config.ts`）に記述し、それをインポートする形式にします。  
まず `site.config.ts` には、`siteConfig` として `url` と `basePath` を設定します。
これらを `astro.config.ts` でインポートし、検証と正規化をしてから `astro.config.ts` の `defineConfig` に渡します。

```ts
export const siteConfig = {
    url: 'https://example.com',
    basePath: '/'
} as const;
```

### site
`siteConfig.url` が有効な URL であるかチェックし、失敗したらエラーをスローします。成功したら `string` 型に戻し、末尾の `/` を削除してから `site` に代入します。

```ts
let site: string;
try {
    site = new URL(siteConfig.url).toString().replace(/\/+$/, '');
} catch (error) {
    throw new Error(
        '[site.config] url is invalid',
        { cause: error }
    );
}
```

- `try` ブロック内で `site` に代入するため、まず `let` で `site` を宣言しておきます。

### base
`siteConfig.basePath` が `/` で始まるかチェックし、失敗したらエラーをスローします。成功したら、末尾の `/` を削除してから `base` に代入します。なお、空文字列になった場合は `/` を代入します。

```ts
if (!siteConfig.basePath.startsWith('/')) {
    throw new Error(
        '[site.config] basePath must start with "/"'
    );
}
const base = siteConfig.basePath.replace(/\/+$/, '') || '/';
```

### defineConfig
設定した `site` と `base` を `defineConfig` に渡します。

```ts
export default defineConfig({
    site,
    base,
})
```
