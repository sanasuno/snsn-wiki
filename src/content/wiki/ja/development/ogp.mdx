## OGP 画像について
各ページごとに OGP 画像を生成します。生成には `satori` と `resvg-js` を用います。
画像には、サイト名、各ページのタイトルと説明、カテゴリを記述します。

## 画像配信エンドポイント
`./src/pages/[locale]/og/[...slug].png.ts` に、画像配信エンドポイントを記述します。

### getStaticPaths()
各ページ用の OGP 画像を配置する URL を組み立てます。また、画像のレンダーに必要な各種情報も `props` として出力します。

ウィキページでは `resolveWikiPages()` 関数を用いてページ情報を格納します。

それ以外のページでは、ロケールごとにサイト全体の情報を記した同じものを使用し、 `slug: 'index'` として出力します。

```ts
export const getStaticPaths = (async () => {
    const resolvedPages = await resolveWikiPages();
    const wikiPaths = resolvedPages.map(({ locale, slug, page }) => {
        const category = getTranslatedCategory(page.id, locale, page.data.isSubPage);
        return {
            params: {
                locale,
                slug: slug === '' ? 'wiki' : `wiki/${slug}`,
            },
            props: {
                title: page.data.title,
                description: page.data.description,
                category,
                siteName: t('site.title', locale),
            },
        };
    });
    const fallbackPaths = locales.map((locale) => ({
        params: {
            locale,
            slug: 'index',
        },
        props: {
            title: t('site.title', locale),
            description: t('site.description', locale),
            category: undefined,
            siteName: t('site.title', locale),
        },
    }));
    return [...wikiPaths, ...fallbackPaths];
}) satisfies GetStaticPaths;
```

### GET
OGP 画像をレンダリングして返します。

```ts
export const GET: APIRoute = async ({ props }) => {
    const { title, description, category, siteName } = props as { title: string; description?: string; category?: string; siteName: string; };
    const png = await renderOgImage({ title, description, category, siteName });
    return new Response(new Uint8Array(png), {
        headers: {
            'Content-Type': 'image/png',
            'Cache-Control': 'public, max-age=31536000, immutable',
        },
    });
};
```

## OGP の記述
`@layouts/MainLayout.astro` に、画像を含めた各種 OGP 設定を記述します。

```astro
---
const ogSlug = currentPath.startsWith(wikiBaseUrl)
    ? removeTrailingSlash(`${currentPath.slice(localeBaseUrl.length)}`)
    : 'index';
const ogImageUrl = new URL(`${localeBaseUrl}og/${ogSlug}.png`, Astro.url).href;
---
<meta property="og:title" content={title} />
<meta property="og:description" content={pageDescription} />
<meta property="og:url" content={canonicalUrl} />
<meta property="og:type" content={currentPath.startsWith(wikiBaseUrl) ? 'article' : 'website'} />
<meta property="og:site_name" content={siteTitle} />
<meta property="og:locale" content={t('og.locale', locale)} />
<meta property="og:image" content={ogImageUrl} />
<meta property="og:image:width" content="1200" />
<meta property="og:image:height" content="630" />
<meta name="twitter:card" content="summary_large_image" />
<meta name="twitter:title" content={title} />
<meta name="twitter:description" content={pageDescription} />
<meta name="twitter:image" content={ogImageUrl} />
```
