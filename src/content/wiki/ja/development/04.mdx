`@layouts/MainLayout.astro`ファイルにサイト全体のレイアウトを記述します。ここから各部位のレイアウトコンポーネントを読み込んで配置します。  

## HTMLヘッダー


### 文字コードとビューポートの設定
文字コードとビューポートを設定します。

```astro
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

### タイトルとディスクリプション

各ページのタイトルとディスクリプションをpropsから取得し、サイト全体のタイトル及びディスクリプションと組み合わせて記述します。  
サイト全体のタイトル及びディスクリプションは、i18n翻訳ファイルに記述し、翻訳関数`t()`を通して設定する形式です。  
タイトルは個別ページのタイトルとサイトタイトルを併記し、ディスクリプションは個別ページのディスクリプションがあればそれを使用、なければサイトディスクリプションを使用します。

```astro
---
interface Props {
    title: string;
    description?: string;
    locale?: Locale;
}
const { title, description, locale = defaultLocale } = Astro.props;
const siteTitle = t('site.title', locale);
const siteDescription = t('site.description', locale);
const pageTitle = `${title} | ${siteTitle}`;
const pageDescription = description ?? siteDescription;
---
<title>{pageTitle}</title>
<meta name="description" content={pageDescription} />
```

### ジェネレーター
ジェネレーターを記述します。

```astro
<meta name="generator" content="snsn-wiki" />
```

### ベースURL
各種ベースURLを定義します。

```ts
const baseUrl = getBaseUrl();
const localeBaseUrl = getLocaleBaseUrl(locale);
const wikiBaseUrl = getWikiBaseUrl(locale);
```

### ファビコン
ファビコンを`ico`形式と`svg`形式の2種類記述します。  
`svg`形式が利用できない環境では`ico`形式のファビコンが表示されます。

```astro
<link rel="icon" href={new URL(`${baseUrl}favicon.ico`, Astro.url).href} sizes="48x48" />
<link rel="icon" href={new URL(`${baseUrl}favicon.svg`, Astro.url).href} type="image/svg+xml" />
```

### サイトマップ
まず、`sitemap`インテグレーションをインストールします。

```sh
npx astro add sitemap
```

次に、`astro.config.ts`に`sitemap`インテグレーションの設定を記述します。

```ts
export default defineConfig({
    integrations: [
        mdx(),
        sitemap({
            i18n: {
                defaultLocale,
                locales: Object.fromEntries(locales.map(locale => [locale, t('lang.locale', locale)]))
            }
        })
    ]
});
```

```astro
<link rel="sitemap" href={new URL(`${baseUrl}sitemap-index.xml`, Astro.url).href} />
```

### カノニカルURL
カノニカルURLを記述します。

```astro
---
const canonicalUrl = new URL(currentPath, Astro.url).href;
---
<link rel="canonical" href={canonicalUrl} />
```

### 代替リンク
代替リンクを記述します。

```astro
---
const defaultAlternateLink = alternateLinks.find(link => link.locale === defaultLocale);
---
{defaultAlternateLink && <link rel="alternate" href={new URL(defaultAlternateLink.href, Astro.url).href} hreflang="x-default" />}
{alternateLinks.map(link => <link rel="alternate" href={new URL(link.href, Astro.url).href} hreflang={link.locale} />)}
```

### Google Fonts
Google Fonts用のURLを記述します。

```astro
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Noto+Sans+Mono:wght@100..900&family=Noto+Sans:ital,wght@0,100..900;1,100..900&family=Noto+Serif:ital,wght@0,100..900;1,100..900&display=swap" rel="stylesheet">
<link href="https://fonts.googleapis.com/css2?family=Noto+Sans+JP:wght@100..900&family=Noto+Serif+JP:wght@200..900&display=swap" rel="stylesheet">
```

### Font Awesome
`Font Awesome` をインストールします。

```sh
npm install --save @fortawesome/fontawesome-free
```

ヘッダー内に記述します。

```ts
import '@fortawesome/fontawesome-free/css/all.min.css';
```
