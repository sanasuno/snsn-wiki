`@lib/path.ts` は、パス関連のライブラリです。

## インポート・再エクスポート

```ts
import { isLocale, type Locale } from '@lib/i18n';
import { normalizeSlugLike } from '@lib/slug-core';
export { normalizeSlugLike }
```

<code>[[slug-core.ts#normalizeSlugLike|normalizeSlugLike()]]</code> 関数は、このファイルからも公開します。

## removeTrailingSlash()
パス末尾のスラッシュを1つ削除する関数です。

```ts
export function removeTrailingSlash(path: string): string {
    return path.replace(/\/$/, '');
}
```

## ensureTrailingSlash()
パス末尾にスラッシュがない場合、スラッシュを付与して返す関数でたに付与せず、す。既に末尾にスラッシュがある場合はそのまま返します。

```ts
export function ensureTrailingSlash(path: string): string {
    return path.endsWith('/') ? path : `${path}/`;
}
```

## getLocale()
ページ ID からロケールを取得する関数です。ID の先頭の要素をロケールとして返します。
- <code>[[i18n.ts#isLocale|isLocale()]]</code> 関数で有効かどうか判定し、有効でなかった場合はエラーをスローします。

```ts
export function getLocale(pageId: string): Locale {
    const parts = pageId.split('/');
    if (isLocale(parts[0])) {
        return parts[0] as Locale;
    }
    throw new Error(`[Invalid id format] ${pageId}`);
}
```

## getRawSlug()
ページ ID から生のスラッグを取得する関数です。先頭のロケール部分を取り除いたものを返します。

```ts
export function getRawSlug(pageId: string): string {
    const parts = pageId.split('/');
    if (isLocale(parts[0])) {
        return parts.slice(1).join('/');
    }
    throw new Error(`[Invalid id format] ${pageId}`);
}
```

## getNormalizedSlug()
ページ ID から正規化済みのスラッグを取得する関数です。`getRawSlug()` 関数で取得したスラッグに <code>[[slug-core.ts#normalizeSlugLike|normalizeSlugLike()]]</code> 関数による正規化を施します。

```ts
export function getNormalizedSlug(pageId: string): string {
    const rawSlug = getRawSlug(pageId);
    return normalizeSlugLike(rawSlug);
}
```

## getBaseUrl()
サイトのベース URL を取得する関数です。
- 環境変数から `BASE_URL` を取得し、`ensureTrailingSlash()` 関数で末尾のスラッシュを確保して返します。

```ts
export function getBaseUrl(): string {
    return ensureTrailingSlash(import.meta.env.BASE_URL);
}
```

## getLocaleBaseUrl()
ロケールベース URL を取得する関数です。
- ベース URL の後ろにロケールを追加した URL を返します。

```ts
export function getLocaleBaseUrl(locale: Locale): string {
    return ensureTrailingSlash(`${getBaseUrl()}${locale}`);
}
```

## getLocalePathUrl()
ロケールベース URL に任意のパスを追加した URL を返す関数です。

```ts
export function getLocalePathUrl(locale: Locale, path: string): string {
    return ensureTrailingSlash(`${getLocaleBaseUrl(locale)}${path.replace(/^\/+/, '')}`);
}
```

## getWikiBaseUrl()
ウィキベース URL を取得する関数です。
- ロケールベース URL の後ろに `wiki` を追加した URL を返します。

```ts
export function getWikiBaseUrl(locale: Locale): string {
    return ensureTrailingSlash(`${getLocaleBaseUrl(locale)}wiki`);
}
```

## getWikiUrl()
ページ ID からウィキページの URL を取得する関数です。
- ロケールを指定した場合は URL のロケール部分のみが指定ロケールの URL を返します。

```ts
export function getWikiUrl(pageId: string, locale: Locale = getLocale(pageId)): string {
    const slug = getNormalizedSlug(pageId);
    if (/[?#%\\]/.test(slug)) {
        throw new Error(`[wiki routing] Unsafe characters in slug: ${pageId}`);
    }
    return ensureTrailingSlash(`${getWikiBaseUrl(locale)}${slug}`);
}
```

## getTagUrl()
タグページの URL を取得する関数です。タグ名は URL 用にエンコードされます。

```ts
export function getTagUrl(locale: Locale, tag: string): string {
    return getLocalePathUrl(locale, `tag/${encodeURIComponent(tag)}`);
}
```

## getCategoryUrl()
カテゴリページの URL を取得する関数です。
- カテゴリは階層構造を持つので、階層を区切る `/` がエンコード処理に巻き込まれないよう、階層ごとにエンコードします。

```ts
export function getCategoryUrl(locale: Locale, category: string): string {
    const encoded = category.split('/').filter(Boolean).map(encodeURIComponent).join('/');
    return getLocalePathUrl(locale, `category/${encoded}`);
}
```

## getCurrentPath()
URL オブジェクトのパスネームを取得する関数です。主に `Astro.url` を渡して現在のパスを取得することを想定しています。

```ts
export function getCurrentPath(url: URL): string {
    return ensureTrailingSlash(url.pathname);
}
```

## decodePath()
エンコードされた URL パスをデコードする関数です。デコードに失敗した場合は、元のパスを返します。末尾の `/` も確保されます。

```ts
export function decodePath(path: string): string {
    try {
        return ensureTrailingSlash(decodeURIComponent(path));
    } catch {
        throw new Error(`[path] Failed to decode path: ${path}`);
    }
}
```

## isPathActive()
現在のパスが指定されたスラッグでアクティブかどうかを判定する関数です。主にナビゲーションにおいて現在の位置を示すために使用されます。
- `exact` パラメータに `true` を設定すると絶対一致で、`false` もしくは未指定の場合は現在のパスが対象スラッグで始まるかどうかで判定します。

```ts
export function isPathActive(targetSlug: string, currentPath: string, exact = false): boolean {
    if (!targetSlug.startsWith('/')) {
        throw new Error(`[path] targetSlug must start with '/': ${targetSlug}`);
    }
    const base = getBaseUrl();
    const decodedCurrentPath = decodePath(currentPath);
    const relativePath = decodedCurrentPath.startsWith(base)
        ? decodedCurrentPath.slice(base.length)
        : decodedCurrentPath;
    const [maybeLocale, ...rest] = relativePath.split('/');
    const currentSlug = isLocale(maybeLocale)
        ? `/${normalizeSlugLike(removeTrailingSlash(rest.join('/')))}`
        : `/${normalizeSlugLike(removeTrailingSlash(relativePath))}`;
    if (exact || targetSlug === '/') {
        return currentSlug === targetSlug;
    }
    return currentSlug === targetSlug || currentSlug.startsWith(`${targetSlug}/`);
}return currentSlug === targetSlug || currentSlug.startsWith(`${targetSlug}/`);
}
```
1. `targetSlug` が `/` で始まるかチェックします。
2. ベース URL を取得します。
3. 現在のパスの URL エンコードをデコードし、末尾の `/` を確保します。
4. 現在のパスがサイトのベース URL で始まる場合、その部分を取り除きます。始まらない場合はそのまま使います。
5. パスを `/` で分割し、最初の要素を `maybeLocale` に、残りを `rest` に格納します。
6. `maybeLocale` を `isLocale()` 関数で判定し、ロケールだった場合は取り除いて正規化します。ロケールでなければそのまま全体を正規化します。
7. `exact` が `true` の場合または `targetSlug` が `/` の場合、完全一致で判定します。
8. それ以外の場合は配下にあるかどうかで判定します。意図しない部分一致を避けるため、完全一致もしくは区切り文字まで含めた一致で判定します。
