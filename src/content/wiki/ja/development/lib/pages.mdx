`@lib/page.ts` は、ページルーティング関連のライブラリです。

## インポート
```ts
import { getCollection, type CollectionEntry } from 'astro:content';
import { defaultLocale } from '@i18n/i18n.config';
import { locales, type Locale } from '@lib/i18n';
import { getLocale, getNormalizedSlug, normalizeSlugLike } from '@lib/path';
```

## ResolvedWikiPage
`resolveWikiPages()` が返すページ情報の型です。

```ts
export interface ResolvedWikiPage {
    locale: Locale;
    slug: string;
    page: CollectionEntry<'wiki'>;
    isFallback: boolean;
    fallbackLocale: Locale;
}
```
- `locale` : ページのロケール
- `slug` : ページのスラッグ
- `page` : ページデータ
- `isFallback` : フォールバックページかどうか
- `fallbackLocale` : フォールバックページのロケール

## 公開済み記事の取得とキャッシュ
`wiki` コレクションから下書きを除いた記事を取得し、本番環境では取得結果をキャッシュします。

### published
記事取得処理の結果を保存する変数です。取得していない状態では `undefined` です。

```ts
let published: Promise<CollectionEntry<'wiki'>[]> | undefined;
```

### load()
`wiki` コレクションから下書きではない記事だけを取得する処理です。

```ts
const load = () => getCollection('wiki', ({ data }) => !data.draft);
```

### getPublishedWikiPages()
記事取得処理を開始する関数です。本番環境ではキャッシュを利用します。

```ts
export const getPublishedWikiPages = () => 
    import.meta.env.PROD ? (published ??= load()) : load();
```

1. 本番ビルド環境かどうかを判定します。
2. 本番ビルド環境の場合、`published` が未設定なら記事取得処理を開始し、その Promise を保存します。`published` が設定済みなら再利用します。
3. 開発環境ではキャッシュを利用せず、毎回 `load()` を呼び出します。これはファイル変更時に古い取得結果が残らないようにするためです。

## resolveWikiPages()
ウィキページを解決する関数です。ウィキページ収集、ロケール・スラッグ抽出、衝突の検知、フォールバック判定を行います。

### 記事整理
#### wikiPages
`getCollection()` 関数で公開設定のウィキページを収集します。

```ts
const wikiPages = await getPublishedWikiPages();
```

#### pagesBySlugLocale
同じ記事のロケール違いをまとめる Map です。スラッグ → ロケール の二重のキーを持ちます。

```ts
const pagesBySlugLocale = new Map<string, Partial<Record<Locale, CollectionEntry<'wiki'>>>>();
```

#### normalizedIdOwners
正規化で ID が衝突する記事を検出するための Map です。

```ts
const normalizedIdOwners = new Map<string, Set<string>>();
```

キーに正規化後、値に正規化前の ID を保存します。

### 記事登録
取得した記事を順番に処理し、2つの Map に登録します。

1. ロケールとスラッグを取得します。
2. スラッグをキーとし、記事を登録します。
3. 正規化前後の ID を紐付けます。

#### locale
記事のロケールです。<code>[[path.ts#getLocale|getLocale()]]</code> 関数を使用します。

```ts
const locale = getLocale(page.id);
```

#### normalizedSlug
```ts
const normalizedSlug = getNormalizedSlug(page.id);
if (/[?#%\\]/.test(normalizedSlug)) {
    throw new Error(`[wiki routing] Unsafe characters in slug: ${page.id}`);
}
```

1. <code>[[path.ts#getNormalizedSlug|getNormalizedSlug()]]</code> 関数でページの ID からロケール部分を取り除き、正規化したスラッグを取得します。
2. スラッグに危険な文字（`?` `#` `%` `\` ）が入っている場合はエラーをスローします。


#### pagesBySlugLocaleへの登録
```ts
if (!pagesBySlugLocale.has(normalizedSlug)) {
    pagesBySlugLocale.set(normalizedSlug, {});
}
pagesBySlugLocale.get(normalizedSlug)![locale] = page;
```
1. スラッグが `pagesBySlugLocale` のキーに存在しなければ、スラッグをキーとして空のオブジェクトを登録します。
2. 現在の記事を、スラッグとロケールをキーとして `pagsBySlugLocale` に登録します。

#### normalizedIdOwnersへの登録
```ts
const normalizedId = normalizeSlugLike(page.id);
if (!normalizedIdOwners.has(normalizedId)) {
    normalizedIdOwners.set(normalizedId, new Set());
}
normalizedIdOwners.get(normalizedId)!.add(page.id);
```
1. 記事 ID を正規化します。
2. 正規化 ID が `normalizedIdOwners` に存在しなければ、正規化 ID をキーとして空の Set を登録します。
3. 正規化前の ID を Set に追加します。

### サブページの親記事検証
```ts
for (const page of wikiPages) {
    if (!page.data.isSubpage) continue;
    const parentSlug = getNormalizedSlug(page.id.split('/').slice(0, -1).join('/'));
    if (!pagesBySlugLocale.has(parentSlug)) {
        throw new Error(`[wiki routing] Parent page not found for subpage: ${page.id}`);
    }
}
```
1. サブページフラグが設定されているか検証します。サブページでなければこのループ処理を終了し、次に進みます。
2. ID の最後の階層を取り除き、正規化したものを親ページのスラッグとします。
3. `pagesBySlugLocale` に親ページのスラッグが登録されていなければ、エラーをスローします。

### ウィキページ解決・フォールバック判定
`pagesBySlugLocale` に登録されているすべてのスラッグとロケールを組み合わせ、フォールバック判定を行ってからウィキページを解決します。

各スラッグについて、全てのロケールでページの存在をチェックします。存在しない場合、同スラッグ・別ロケールのページ内容をフォールバックとして使用します。

フォールバックの優先順は以下の通りです。
1. 本来のロケール
2. デフォルトロケール (`defaultLocale`)
3. 対象のスラッグでページが存在するロケール（ `locales` の配列順に検証）

- ページが存在しない場合、 `isFallback` フラグが `true` になり、 `fallbackLocale` にフォールバック先のロケールが設定されます。
- ページが存在する場合、 `fallbackLocale` には本来のロケールが設定されますが、これは実際には使用されません。
- いずれのロケールでもページが存在しない場合、エラーをスローします。

```ts
const resolved: ResolvedWikiPage[] = [];
for (const slug of Object.keys(pagesBySlugLocale)) {
    const availablePages = pagesBySlugLocale[slug];
    for (const locale of locales) {
        const isFallback = !availablePages[locale];
        let page: CollectionEntry<'wiki'>;
        let fallbackLocale: Locale;
        if (availablePages[locale]) {
            page = availablePages[locale]!;
            fallbackLocale = locale;
        } else if (availablePages[defaultLocale]) {
            page = availablePages[defaultLocale]!;
            fallbackLocale = defaultLocale;
        } else {
            page = locales.map((loc) => availablePages[loc]).find(
                (p): p is CollectionEntry<'wiki'> => p !== undefined
            )!;
            fallbackLocale = getLocale(page!.id);
        }
        if (!page) {
            throw new Error(`[wiki routing] No page found for slug "${slug}"`);
        }
        resolved.push({ locale, slug, page, isFallback, fallbackLocale });
    }
}
```

### 戻り値
解決されたウィキページ情報の配列を返します。

```ts
return resolved;
```

## getUniquePagesByLocale()
対象のページ群に対し、指定ロケール向けに正規化スラッグをキーとした一意のページリストを返す関数です。
- 指定されたロケール、デフォルトロケール、その他のロケール（ `locales` の配列順）の順序で、同じスラッグを持つページ同士で比較し、最も優先度の高いものを格納して返します。

```ts
export function getUniquePagesByLocale( pages: CollectionEntry<'wiki'>[], locale: Locale ): CollectionEntry<'wiki'>[] {
    const priority = (l: Locale) =>
        l === locale
            ? 0
            : l === defaultLocale
                ? 1
                : 2 + locales.indexOf(l);
    const best: Record<string, CollectionEntry<'wiki'>> = {};
    for (const page of pages) {
        const key = getNormalizedSlug(page.id);
        const current = best[key];
        if (!current || priority(getLocale(page.id)) < priority(getLocale(current.id))) {
            best[key] = page;
        }
    }
    return Object.values(best);
}
```
