`@lib/i18n.ts` は、翻訳関連のユーティリティ関数を提供するライブラリです。

## インポート
[[i18n.config.ts]] と [[翻訳キー|keys.ts]] から翻訳データとキー定義をインポートします。

```ts
import { translations, defaultLocale } from '@i18n/i18n.config';
import { translationKeys, type TranslationKey } from '@i18n/keys';
```

## Locale
利用可能なロケールの型です。
- `translations` のオブジェクトが持つプロパティ名から定義されます。

```ts
export type Locale = keyof typeof translations;
```

## locales
利用可能なロケール一覧の配列です。
- `translations` のオブジェクトのキー配列として定義されます。
- `as Locale[]` で配列の要素が `Locale` 型であることを型アサーションしています。

```ts
export const locales = Object.keys(translations) as Locale[];
```

## isLocale()
ロケールの型ガード関数です。渡された文字列が有効なロケールかどうかを判定します。
- `value is Locale` の型述語によって、型スコープ内で `value` の型が `Locale` に絞られます。
- 引数として渡される `value` は `string` 型なので、比較するために `locales` を `readonly string[]` に型アサーションしています。

```ts
export function isLocale(value: string): value is Locale {
    return (locales as readonly string[]).includes(value);
}
```

## isTranslationKey()
翻訳キーの型ガード関数です。渡された文字列が有効な翻訳キーかどうかを判定します。
- `value is TranslationKey` の型述語によって、型スコープ内で `value` の型が `TranslationKey` に絞られます。
- 引数として渡される `value` は `string` 型なので、比較するために `translationKeys` を `readonly string[]` に型アサーションしています。

```ts
export function isTranslationKey(value: string): value is TranslationKey {
    return (translationKeys as readonly string[]).includes(value);
}
```

## t()
翻訳文字列を取得する関数です。
- 引数は翻訳キーとロケール（省略時はデフォルトロケール）です。
- 翻訳が存在しないケースのフォールバックも備えています。

1. 指定された言語の辞書を取得します。
2. 辞書にキーが存在する場合、その値を返し、非 null として扱います。
3. 辞書にキーが存在しない場合、デフォルトロケールの辞書を取得します。
4. デフォルトロケールの辞書にキーが存在する場合、その値を返します。
5. デフォルトロケールの辞書にもキーが存在しない場合、キーの値を返します。

```ts
export function t(key: TranslationKey, locale: Locale = defaultLocale): string {
    const current = translations[locale] as Partial<Record<TranslationKey, string>>;
    if (current[key] !== undefined) {
        return current[key]!;
    }
    const fallback = translations[defaultLocale] as Partial<Record<TranslationKey, string>>;
    return fallback[key] ?? key;
}
```
