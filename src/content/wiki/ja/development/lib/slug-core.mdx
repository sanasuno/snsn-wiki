`@lib/path.ts` は、スラッグ関連のコアライブラリです。

## slugify()
テキストをスラッグに変換する関数です。
```ts
export function slugify(text: string): string {
    return text
        .normalize('NFKC')
        .trim()
        .toLowerCase()
        .replace(/\s+/g, '-');
}
```
1. NFKC で正規化します。
2. 前後の空白を削除します。
3. 英字を小文字に統一します。
4. 空白を `-` に変換します。

## normalizeSlugLike()
スラッグを正規化する関数です。
```ts
export function normalizeSlugLike(rawSlug: string): string {
    const normalized = slugify(rawSlug);
    return normalized === 'index'
        ? ''
        : normalized.replace(/\/index$/, '');
}
```
1. `slugify()` を実行してスラッグを取得します。
2. 結果全体が `index` になった場合は空文字を返します。
3. 末尾に `/index` がある場合はそれを削除して返します。それ以外の場合はそのまま返します。
