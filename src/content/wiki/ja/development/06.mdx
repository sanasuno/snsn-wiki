## CSS 構成
CSS は、以下の3ファイルに記述します。
- `@styles/global.css` : 全体のスタイルを記述するファイル
- `@styles/theme.css` : テーマカラーなどの CSS 変数を記述するファイル
- `@styles/custom.css` : ユーザーカスタム CSS 用のファイル

## ユニバーサルセレクタのリセット
全要素（疑似要素を含む）に対し、 `margin` と `padding` といった余白をゼロにします。

また、 `box-sizing: border-box` により、
`width` / `height` に `padding` と `border` を含めます。
これにより、パディング分はみ出すズレを防げます。

```css
*,
*::before,
*::after {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}
```

## 基本設定
`html` 要素に基本設定を適用します。

```css
html {
    font-size: 16px;
    scroll-padding-top: calc(var(--header-height) + 8px);
    scroll-behavior: smooth;
    -webkit-font-smoothing: antialiased;
    -moz-osx-font-smoothing: grayscale;
}
```

- `font-size` : `rem` 単位の基準値となるフォントのサイズを設定します。
- `scroll-padding-top` : アンカーリンクでのジャンプ時、
見出しが固定ヘッダーに触れないように余白を確保します。
- `scroll-behavior` : ページ内スクロールをスムーズにします。
- `font-smoothing` : フォント描画をなめらかにします。

## モーション軽減対応
`prefers-reduced-motion: reduce` のユーザーに対し、スクロールのスムーズを無効化します。

```css
@media (prefers-reduced-motion: reduce) {
    html {
        scroll-behavior: auto;
    }
}
```

## ベーススタイル
`body` 要素に対してベーススタイルを設定します。

```css
body {
    margin: 0;
    padding: 0;
    font-family: var(--font-sans);
    background-color: var(--color-bg);
    color: var(--color-text);
    line-height: 1.6;
    transition: var(--transition);
}
```

- `margin: 0;` `padding: 0;` はユニバーサルセレクタでも設定していますが、
防御的記述として保証しています。

## 隠し要素
`[hidden]` 属性を持つ要素を非表示にします。

```css
[hidden] {
    display: none !important;
}
```

- `!important` で確実に非表示にします。

## CSS Grid
CSS Grid を使って各コンポーネントの配置レイアウトを決定します。

画面上部にヘッダーを `position: sticky;` で固定し、
その下に CSS Grid を使って左からサイドバー、メインパネル、サブパネルの順に配置します。

3列のグリッドに分割し、左から `sidebar` `main` `sub` の3つを配置します。
これらを CSS Grid の `grid-template-areas` で指定します。

サイドバーとサブパネルの横幅は CSS 変数で指定し、
メインパネルの横幅ははみ出しを防ぐために `minmax(0, 1fr)` を指定します。

```css
.layout {
    display: grid;
    grid-template-columns: var(--sidebar-width) minmax(0, 1fr) var(--subpanel-width);
    grid-template-areas: "sidebar main sub";
    min-height: calc(100dvh - var(--header-height));
}
```

サブパネルを表示しないページでは、`.no-subpanel` クラスが付与され、`sub` 領域が配置されません。

```css
.layout.no-subpanel {
    grid-template-columns: var(--sidebar-width) minmax(0, 1fr);
    grid-template-areas: "sidebar main";
}
```

### レスポンシブ対応
画面幅が1376px以下の場合、サブパネルは配置されず、ドロワーとして表示されます。

```css
@media (width <= 1376px) {
    .layout, .layout.no-subpanel {
        grid-template-columns: var(--sidebar-width) minmax(0, 1fr);
        grid-template-areas: "sidebar main";
    }
}

@media (width <= 1376px) {
    .subpanel {
        position: fixed;
        inset: var(--header-height) 0 0 auto;
        width: min(320px, 90vw);
        height: calc(100dvh - var(--header-height));
        margin-top: 0;
        background-color: var(--color-bg);
        border-left: 1px solid var(--color-border);
        box-shadow: var(--shadow-lg);
        z-index: var(--z-drawer);
        padding: 20px 16px;
        overflow-y: auto;
        transform: translateX(100%);
        transition: transform 150ms ease, visibility 150ms ease;
        scrollbar-width: thin;
    }

    .subpanel.open {
        transform: translateX(0);
        transition: transform 150ms ease, visibility 150ms ease;
    }

    .subpanel:not(.open) {
        visibility: hidden;
    }
}
```

さらに、画面幅が768px以下の場合はメインパネルのみを表示し、
サイドバーは`.open`クラスが付与された場合のみ表示します。

```css
@media (width <= 768px) {
    .layout, .layout.no-subpanel {
        grid-template-columns: minmax(0, 1fr);
        grid-template-areas: "main";
    }
}

@media (width <= 768px) {
    .sidebar {
        position: fixed;
        top: var(--header-height);
        left: calc(-1 * var(--sidebar-width));
        width: var(--sidebar-width);
        height: calc(100dvh - var(--header-height));
        transition: var(--transition);
        visibility: hidden;
    }
    .sidebar.open {
        left: 0;
        width: var(--sidebar-width);
        z-index: var(--z-drawer);
        overflow-y: auto;
        visibility: visible;
        border-right: 1px solid var(--color-border);
        box-shadow: 2px 0 8px rgb(0 0 0 / 0.15);
    }
}
```
