## CSS 構成
CSS は、以下の3ファイルに記述します。
- `@styles/global.css` : 全体のスタイルを記述するファイル
- `@styles/theme.css` : テーマカラーなどの CSS 変数を記述するファイル
- `@styles/custom.css` : ユーザーカスタム CSS 用のファイル

## ユニバーサルセレクタのリセット
全要素（疑似要素を含む）に対し、 `margin` と `padding` といった余白をゼロにします。

また、 `box-sizing: border-box` により、
`width` / `height` に `padding` と `border` を含めます。
これにより、パディング分はみ出すズレを防げます。

```css
*,
*::before,
*::after {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}
```

## 基本設定
`html` 要素に基本設定を適用します。

```css
html {
    font-size: 16px;
    scroll-padding-top: calc(var(--header-height) + 8px);
    scroll-behavior: smooth;
    -webkit-font-smoothing: antialiased;
    -moz-osx-font-smoothing: grayscale;
}
```

- `font-size` : `rem` 単位の基準値となるフォントのサイズを設定します。
- `scroll-padding-top` : アンカーリンクでのジャンプ時、
見出しが固定ヘッダーに触れないように余白を確保します。
- `scroll-behavior` : ページ内スクロールをスムーズにします。
- `font-smoothing` : フォント描画をなめらかにします。

## モーション軽減対応
`prefers-reduced-motion: reduce` のユーザーに対し、スクロールのスムーズを無効化します。

```css
@media (prefers-reduced-motion: reduce) {
    html {
        scroll-behavior: auto;
    }
}
```

## ベーススタイル
`body` 要素に対してベーススタイルを設定します。

```css
body {
    margin: 0;
    padding: 0;
    font-family: var(--font-sans);
    background-color: var(--color-bg);
    color: var(--color-text);
    line-height: 1.6;
    transition: var(--transition);
}
```

- `margin: 0;` `padding: 0;` はユニバーサルセレクタでも設定していますが、
防御的記述として保証しています。

## 隠し要素
`[hidden]` 属性を持つ要素を非表示にします。

```css
[hidden] {
    display: none !important;
}
```

- `!important` で確実に非表示にします。

## CSS Grid
CSS Gridを使って、レイアウトの各コンポーネントごとに配置を決定します。  
`header`、`sidebar`、`main`、`sub`の4つの領域を配置します。

```css
.layout {
    display: grid;
    grid-template-rows: var(--header-height) 1fr;
    grid-template-columns: var(--sidebar-width) minmax(0, 1fr) var(--subpanel-width);
    grid-template-areas: 
        "header header header"
        "sidebar main sub";
    min-height: 100dvh;
}
```

サブパネルを表示しない記事では、`.no-subpanel` クラスが付与され、`sub` 領域が配置されません。

```css
.layout.no-subpanel {
    grid-template-columns: var(--sidebar-width) minmax(0, 1fr);
    grid-template-areas:
        "header header"
        "sidebar main";
}
```

画面幅が1200px以下の場合、サブパネルを配置せず、表示もしません。

```css
@media(max-width: 1200px) {
    .layout{
        grid-template-columns: var(--sidebar-width) minmax(0, 1fr);
        grid-template-areas:
            "header header"
            "sidebar main";
    }
}

@media(max-width: 1200px) {
    .subpanel {
        display: none;
    }
}
```

さらに、画面幅が768px以下の場合、メインコンテンツのみ表示し、サイドバーは`.open`クラスが付与された場合のみ表示されます。

```css
@media (max-width: 768px) {
    .layout, .layout.no-subpanel {
        grid-template-columns: minmax(0, 1fr);
        grid-template-areas:
            "header"
            "main";
    }
}

@media(max-width: 768px) {
    .sidebar {
        display: block;
        position: fixed;
        top: var(--header-height);
        left: calc(-1 * var(--sidebar-width));
        width: var(--sidebar-width);
        height: calc(100dvh - var(--header-height));
        transition: var(--transition);
        visibility: hidden;
    }
    .sidebar.open {
        left: 0;
        width: var(--sidebar-width);
        z-index: 1000;
        overflow-y: auto;
        visibility: visible;
    }
}
```

`.site-header` は `grid-area: 1 / 1 / -1 / -1` で全行にまたがらせ、
`align-self: start` で 56px に抑えています。
`grid item` の `position: sticky` は自身の `grid area` の中でしか動けないため、
`row 1` だけに置くと追従しません。
`grid-template-areas` の `header` は、ここでは実質ダミーです。
カラムは `1fr` ではなく `minmax(0, 1fr)` にします。
`1fr` は `minmax(auto, 1fr)` なので、
長いコードブロックの `min-content` 幅でカラムが押し広げられます。
`.main-panel` の `min-width: 0` も同じ理由です。
