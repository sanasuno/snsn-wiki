## ヘッダー構成
ヘッダーは、`@layouts/Header.astro` に記述します。

```astro
<header class="site-header">
    /* ここにヘッダー内容を記述 */
</header>
```

`.site-header` クラスにヘッダーのスタイルを記述します。
`position: sticky;` を指定して、スクロール時にヘッダーが追従するようにします。

```css
.site-header {
    position: sticky;
    top: 0;
    z-index: var(--z-header);
    height: var(--header-height);
    display: flex;
    align-items: center;
    gap: 16px;
    padding: 0 20px;
    background-color: var(--color-bg);
    border-bottom: 1px solid var(--color-border);
}
@media(max-width: 768px) {
    .site-header {
        gap: 8px;
        padding: 0 12px;
    }
}
```

### サイドバー切り替えスクリプト
サイドバー切り替え用のスクリプトを `@scripts/sidebar.ts` に記述します。

### setSidebarToggleBtnState()
サイドバー切り替えボタンの状態を設定する関数です。
ボタン要素とサイドバーの開閉状態を受け取り、`aria-expanded` 属性とアイコンを切り替えます。

```ts
function setSidebarToggleBtnState(btn: HTMLButtonElement, isOpen: boolean) {
    btn.setAttribute('aria-expanded', isOpen.toString());
    const icon = btn.querySelector('i');
    if (icon) {
        icon.classList.toggle('fa-bars', !isOpen);
        icon.classList.toggle('fa-times', isOpen);
    }
}
```

### sidebarToggle()
サイドバー切り替えボタンの動作を制御する関数です。
ボタンをクリックするとサイドバーの開閉状態を切り替え、`aria-expanded` 属性とアイコンを更新します。
また、サイドバーが開いている状態で、サイドバー外をクリックするとサイドバーを閉じます。

まず、サイドバーと切り替えボタンの要素を取得します。存在しなければ処理を終了します。

```ts
const sidebar = document.getElementById('sidebar');
if (!sidebar) return;
const sidebarToggleBtn = document.getElementById('sidebar-toggle');
if (!(sidebarToggleBtn instanceof HTMLButtonElement)) return;
```

`dataset.initialized` を使って、すでに初期化済みかどうかを判定します。

```ts
if (sidebarToggleBtn.dataset.initialized === 'true') return;
sidebarToggleBtn.dataset.initialized = 'true';
```

サイドバーがすでに開いている状態でページが読み込まれた場合、切り替えボタンの状態を開いた状態に更新します。

```ts
const initialOpen = sidebar.classList.contains('open');
setSidebarToggleBtnState(sidebarToggleBtn, initialOpen);
```

ボタンをクリックしたときのイベントリスナーを追加します。
サイドバーの開閉状態を切り替え、切り替えボタンの状態も更新します。

```ts
sidebarToggleBtn.addEventListener('click', (e) => {
    e.stopPropagation();
    sidebar.classList.toggle('open');
    const isOpen = sidebar.classList.contains('open');
    setSidebarToggleBtnState(sidebarToggleBtn, isOpen);
});
```

ドキュメント全体にクリックイベントリスナーを追加し、
サイドバー外・ボタン外をクリックしたとき、
サイドバーが開いている状態ならサイドバーを閉じます。

```ts
document.addEventListener('click', (e) => {
    if (
        e.target instanceof Element &&
        sidebar.classList.contains('open') &&
        !sidebar.contains(e.target) &&
        !sidebarToggleBtn.contains(e.target)
    ) {
        sidebar.classList.remove('open');
        setSidebarToggleBtnState(sidebarToggleBtn, false);
    }
});
```

### テーマ初期化
`MainLayout.astro`内に、インラインスクリプトでテーマ初期化処理を記述します。  
テーマの初期値は、ユーザーが保存したテーマ（`localStorage`）を優先し、存在しない場合はブラウザの設定（`prefers-color-scheme`）から決定します。

```astro
<script is:inline>
    (function() {
        let savedTheme = null;
        try { savedTheme = localStorage.getItem('theme'); } catch (e) {}
        if (savedTheme) {
            document.documentElement.setAttribute('data-theme', savedTheme);
        } else {
            const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
            document.documentElement.setAttribute('data-theme', prefersDark ? 'dark' : 'light');
        }
    })();
</script>
```

### ローカルストレージ操作スクリプト
`@scripts/localStorage.ts` に、ローカルストレージ操作用の関数を記述します。

#### setLocalStorage
ローカルストレージに値を保存する関数です。

```ts
export function setLocalStorage(key: string, value: string): boolean {
    try {
        localStorage.setItem(key, value);
        return true;
    } catch (error) {
        console.error(`Failed to set localStorage key: ${key}`, error);
        return false;
    }
}
```

#### getLocalStorage
ローカルストレージから値を取得する関数です。

```ts
export function getLocalStorage(key: string): string | null {
    try {
        return localStorage.getItem(key);
    } catch (error) {
        console.error(`Failed to get localStorage key: ${key}`, error);
        return null;
    }
}
```

### テーマ制御スクリプト
テーマ切り替えボタンの動作を制御するスクリプトを `@scripts/theme.ts` に記述します。

```ts
import { setLocalStorage } from "@scripts/localStorage";
export function themeToggle() {
    const btn = document.getElementById('theme-toggle')
    if (!btn) return;

    const syncPressedState = () => {
        const currentTheme = document.documentElement.getAttribute('data-theme');
        const isDark = currentTheme === 'dark';
        btn.setAttribute('aria-pressed', isDark ? 'true' : 'false');
    }
    
    syncPressedState();

    btn.addEventListener('click', () => {
        const currentTheme = document.documentElement.getAttribute('data-theme');
        const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
        const isDark = currentTheme === 'dark' || (!currentTheme && prefersDark);
        const nextTheme = isDark ? 'light' : 'dark';
        document.documentElement.setAttribute('data-theme', nextTheme);
        setLocalStorage('theme', nextTheme);
        syncPressedState();
    })
}
```

`@scripts/main.ts` から `themeToggle` 関数を呼び出します。

```ts
import { themeToggle } from "@scripts/theme";
themeToggle();
```

`MainLayout.astro` にスクリプトを追加します。

```astro
<script>
    import "@scripts/main";
</script>
```
